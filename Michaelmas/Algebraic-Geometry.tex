\subsection*{Why suffer through this? (Weil conjectures)}

The Weil conjectures link two worlds. The starting data is a homogeneous polynomial \(f \in \Z[x_0, \dots, x_n] = \Z[\bf x]\), of degree \(d\).

\textbf{World 1:} We can consider the vanishing locus

\[X = \bb V(f) = \left\{(a_0: \dots : a_n) \mid f(a_0, \dots, a_n) = 0\right\} \subseteq \bb P^1_\C\]

which is a projective hypersurface. We will assume that \(X\) is smooth, i.e. there is no point \(p \in X\), such that all of the partial derivatives \(\pdv{f}{x_i}(p)\) vanish for all \(i\). If we view \(\bb P^n\) as \((\C^{n+1} \setminus 0)/\text{scaling}\), and \(\C^{n+1}\setminus 0\) is given the Euclidean topology, then \(X\) is a (complex) manifold. This follows from the inverse/implicit function theorem. Moreover, \(X\) is a compact topological space. In fact, \(X\) can be triangulated. 

With this, we can consider various invariants associated to \(X\). The simplest is the Euler characteristic \(\chi(X)\). For example, \(\chi(\bb P^k) = k+1\). More generally, we can consider the Betti numbers \(b_i\), where

\[b_i = \dim_\Q H_i(X; \Q)\]

are the dimension of the rational homology groups. In this case,

\[\chi(X) = \sum_i(-1)^i b_i\]

\textbf{World 2:} Fix a prime \(p\), such that \(X\) is smooth over \(\overline{\bb F_p}\) (exercise: \(p\) exists). Define \(N_m\) to be the number of points in \(X\left(\bb F_{p^m}\right)\).

We can package the data of the \(N_m\)s: Consider the formal power series

\[\zeta(X, t) = \exp(\sum_{m=1}^\infty \frac{N_m}{m} t^m)\]

which is the \emph{Weil \(\zeta\) function}.

\begin{theorem}
    [Grothendieck]

    \leavevmode

    \begin{enumerate}
        \item \(\zeta(X, t)\) is a rational functon. That is, \[\zeta(X, t) = \frac{P_0(t)\cdots P_{2n-2}(t)}{P_1(t)\cdots P_{2n-3}(t)}\] where each \(P_i(t)\) is a polynomial.
        \item The degree of the polynomial \(P_i(t)\) is \(b_i(X)\).
    \end{enumerate}
\end{theorem}

Deligne proved the Riemann Hypothesis for the Weil \(\zeta\) function.

\section{Beyond Algebraic Varieties}

\subsection{Summary of affine varieties}

Let \(k = \overline k\) be an algebraically closed field. We would like to consider subsets

\[\van(S) \subseteq \aff k n\]

where \(S \subseteq k\poly n\). Up to isomorphism, this is the same as finitely generated \(k\)-algebras without nilpotent elements. Given \(V = \bb V(S)\), we have an ideal \[I(V) = \left\{f \in k\poly n \mid f = 0 \text{ on }V\right\}\]

We can then define

\[k[V] = \frac{k\poly n}{I(V)}\]

Conversely, given \(k[V]\), a finitely generated nilpotent-free \(k\)-algebra. Choosing generators \(y_1, \dots, y_n\) of the algebra, we have a surjection \(\pi: k[x_1, \dots, x_n] \surj k[V]\), sending \(x_i\) to \(y_i\). We can then take

\[V = \van(\ker(\pi))\]

\lec

Let \(\sqrt I\) be the radical of an ideal \(I\) be

\[\sqrt I = \left\{f \in k\polys \mid f^m \in I \text{ for some }m\right\}\]

Then \(\van(S) = \van(\inner{S}) = \van(\sqrt{\inner{S}})\), where \(\inner{S}\) is the ideal generated by \(S\). In this case, we have a correspondence between affine varieties in \(\aff k n\) and radical ideals in \(k\polys\).

\begin{remark}
    This awkwardness caused by ``in affine space'' can be removed, by considering varieties up to isomorphism, and coordinate rings (i.e. finitely generated nilpotent free \(k\)-algebras).
\end{remark}

\subsubsection{Basic structures}

\begin{itemize}
    \item \(k\polys\) is the ring of algebraic functions on \(\aff k n\).
    \item \(I \subseteq k\polys\) is a radical ideal.
    \item The coordinate ring of \(V = \van(I)\) is \(k[V] = k\polys/I\).
\end{itemize}

This coordinate ring is the basic object, it's more fundamental than \(I\).

\subsubsection{Topology}

Fix an affine variety \(V \subseteq \aff k n\). It has a Zariski topology, where the closed sets are subsets of the form

\[V \cap \van(S)\]

where \(S \subseteq k\polys\). Equivalently, we can consider the Zariski topology on \(\aff k n\), and then equip \(V\) with the subspace topology.

Intrinsically, we can say that \(W \subseteq V\) is closed if we have that

\[W = \van(J)\]

where \(J \subseteq k[V]\) is an ideal. Exercise: these two topologies are the same.

\subsubsection{Nullstellensatz}

That is, what are the maximal ideals in \(k\polys\)? Equivalently, in a nilpotent free finitely generated \(k\)-algebra \(k[V]\)?

Fix \(V = \van(I)\), and pick \(p \in V\). There is a natural ring homomorphism \(\ev_p : k[V] \to k\), given by \(\ev_p(f) = f(p)\).

\begin{claim}
    \(\ev_p\) is surjective.
\end{claim}

\begin{proof}
    Exercise.
\end{proof}

The kernel of \(\ev_p\) is a maximal ideal in \(k[V]\). Therefore, points on \(V\) are one source of maximal ideals.

\begin{theorem}
    [Nullstellensatz] There is a bijection
    
    \begin{align*}
        \left\{\text{points in }V\right\} &\bij \left\{\text{maximal ideals in }k[V]\right\}
    \end{align*}
\end{theorem}

\subsubsection{Functions}

Each \(f \in k[V]\) gives a function \(V \to k (= \aff k 1)\), sending \(p\) to \(f(p)\). Equivalently, if we denote \(\mfm_p = \ker(\ev_p)\), then this is the quotient map

\[k[V] \surj k = k[V]/\mfm_p\]

\subsubsection{Morphisms}

Given \(V \subseteq \aff k n\), \(W \subseteq \aff k m\), morphisms \(V \to W\) are constructed as follows.

\begin{enumerate}
    \item Take functions \(f_1, \dots, f_m \in k\poly n\).
    \item This gives a map \(\varphi = (f_1, \dots, f_m) : V \to \aff k m\).
    \item A morphism \(V \to W\) must additionally satisfy that \(\varphi(V) \subseteq W\).
\end{enumerate}

There is a more intrinsic construction. Any such \(\varphi : V \to W\) as above, gives rise to a pullback map \(\varphi^* : k[W] \to k[V]\), where \(\varphi^*(g) = g \circ \varphi\).

There is a bijection

\[\set{\text{Morphisms }V \to W} \bij \set{k\text{-algebra homomorphisms }k[W] \to k[V]}\]

In practice, the right hand side is much cleaner than the right hand side.

\underline{Lesson:} We \(\heartsuit\) coordinate rings.

\underline{Upshot:} Let \(R\) be a finitely generated, nilpotent free \(k\)-algebra, the topological space

\[X_R = \left\{\mfm \subseteq R \mid \mfm \text{ is a maximal ideal}\right\}\]

Closed sets are given by \(\van(S)\), for \(S \subseteq R\).

\subsection{Limitations}

\begin{question}
    What is an abstract (not necessarily affine) variety?
\end{question}

Morally, it's an object which locally looks like an affine variety.

\begin{example}
    [Non-algebraically closed fields] Consider the ideal

    \[I = \inner{x^2 + y^2 + 1} \in \R[x, y]\]

    Then \(\van(I) = \emptyset \subseteq \R^2\). \(I\) is a prime ideal, therefore radical, so the na\"ive Nullstellensatz fails.
\end{example}

\begin{question}
    Given a commutative ring \(R\), is there a natural topological space \(X_R\), on which \(R\) is the ring of functions? For example, \(R = \Z, \Z[x]\) and so on.
\end{question}

\begin{example}
    [Why restrict to radical ideals] Assume \(k = \overline k\).

    \[C = \van(y - x^2) \subseteq \aff k n\]

    and

    \[D = \van(y)\]

    Then

    \[C \cap D = \van(y, y-x^2) = \van(x^2, y) = \left\{(0, 0)\right\}\]

    But \(\inner{y, y-x^2}\) has radical \(\inner{x, y}\), it is not equal to the ideal \(\inner{x, y}\). The intersection wants to be two points. Take

    \[D_{\delta} = \van(y + \delta)\]

    where \(\delta \in k \setminus 0\), then \(C \cap D_\delta\) has two points.
\end{example}

\subsection{Spectrum of a ring}

\underline{Basic idea:} Given a ring \(A\), we will define

\[\Spec(A) = \left\{\mfp \subseteq A \mid \mfp \text{ a prime ideal}\right\}\]

Why prime?

\begin{itemize}
    \item Functoriality - \(A \to B\) induces \(\Spec(B) \to \Spec(A)\) by pullback.
    \item Some rings have very few maximal ideals.
\end{itemize}

\lec

Let \(A\) be a commutative ring,

\underline{Goal:} Define a topological space \(X_A\) on which \(A\) is naturally the ring of functions.

\begin{definition}
    [Zariski spectrum] The Zariski spectrum of \(A\) is

    \[\Spec(A) = \set{\mfp \subseteq A \mid \mfp \text{ a prime ideal}}\]
\end{definition}

\begin{remark}
    We might also consider the maximal ideal spectrum, but this fails to be functorial. That is, a ring homomorphism \(\varphi: A \to B\) induces a map \(\varphi^* = \varphi^{-1} : \Spec(B) \to \Spec(A)\), by considering the preimage. On the other hand, no such map exists for maximal ideals.
\end{remark}

\underline{Why?} Whatever \(X_A\) could be, given a point \(p \in X_A\), we should have an evaluation map

\begin{align*}
    \ev_p : A &\to K_p \\
    f &\mapsto f(p)
\end{align*}

where \(K_p\) is a field. Note we allow the field \(K_p\) to depend on \(p\). Nor are we requiring that \(\ev_p\) be surjective. The image of \(\ev_p\) is an integral domain, and moreover, any map to an integral domain \(R\) is also a map to a field \(F = \Frac(R)\).

Subject to this, homomorphisms \(f : A \to K\), with \(K\) a field, corresponds to \(\ker(f)\), which is a prime ideal.

\begin{example}
    Taking \(A = \Z\), we have that

    \[\Spec(\Z) = \left\{\inner{p} \mid p \in \N \text{ a prime}\right\} \cup \left\{0\right\}\]

    Pick a function \(123 \in \Z\). Now evaluate at different points, which is just reduction modulo \(p\), i.e.

    \begin{align*}
        123(2) &= 1 \in \Z/2 \\
        123(3) &= 0 \in \Z/3 \\
        123(0) &= 123 \in \Z \subseteq \Q
    \end{align*}
\end{example}

\begin{example}
    Taking \(A = \R[x]\), \(\Spec(A)\) has elements corresponding to 
    
    \begin{enumerate}
        \item irreducible quadratics in \(x\), e.g. \(\inner{x^2 + 1}\), which corresponds to \((\C\backslash\R)/\text{complex conjugation}\).
        \item linear polynomials in \(x\), e.g. \(\inner{x-2}\), corresponding to \(\R\),
        \item \(0\).
    \end{enumerate}

    Hence \(\Spec(A)\) is the upper half plane, plus the point zero.
\end{example}

\begin{definition}
    If \(A\) is an integral domain, then \(0 \in \Spec(A)\) is called the generic point.
\end{definition}

\begin{remark}
    The value of \(f \in A\) at \(\mfp \in \Spec(A)\) is \(f + \mfp \in A/\mfp\).
\end{remark}

\subsection{Topology on \(\Spec(A)\)}

\underline{Motivation:} In the Zariski topology, the zero sets should be the vanishing sets of functions. Fix \(f \in A\), define the vanishing set of \(f\) to be

\[\van(f) = \left\{\mfp \in \Spec(A) \mid f \in \mfp\right\} = \left\{\mfp \in \Spec(A) \mid f(\mfp) = 0 \in A/\mfp\right\}\]

More generally, if \(I \subseteq A\) is an ideal, then

\[\van(I) = \left\{\mfp \in \Spec(A) \mid I \subseteq \mfp\right\} = \left\{\mfp \in \Spec(A) \mid f(\mfp) = 0 \text{ for all }f\in I\right\}\]

\begin{definition}
    The sets \(\van(I) \subseteq \Spec(A)\), for \(I \subseteq A\) ideals, satisfy the requirements for closed sets in a topological space. 
\end{definition}

\begin{proof}
    Easy to see \(\emptyset\) and \(\Spec(A)\) are closed. Moreover,

    \[\bigcap_\alpha \van(I_\alpha) = \van\left(\sum_\alpha I_\alpha\right)\]

    and

    \[\van(I_1) \cup \van(I_2) = \van(I_1 \cap I_2)\]

    For this, \(\subseteq\) is clear. For the reverse containment,

    \[I_1I_2 \subseteq I_1\cap I_2\]

    If \(\mfp \supseteq I_1 \cap I_2\), then it contains \(I_1I_2\). Since \(\mfp\) is prime, then either \(I_1\) or \(I_2\) is contained in \(\mfp\).
\end{proof}

\begin{example}
    Let \(k = \overline k\), and \(A = k[x, y]\). Then
    
    \[\Spec(A) \supseteq \maxSpec(A) = k^2\]

    where \(\maxSpec(A)\) is the set of maximal ideals, which by the Nullstellensatz corresponds to the points in \(\aff k 2\). There is a point for each non-maximal prime ideal, e.g.

    \[\inner{x - y} \quad \inner{y^2 - x^3}\quad\inner{y-x^2}\]

    Consider the generic point \(0 \in \Spec(A)\). Then the closure of \(\{0\}\) is \(\Spec(A)\). On the other hand, the closure of a maximal ideal is itself.

    Now consider the ideal \(\inner{f}\), where \(f\) is an irreducible polynomial, e.g. \(y^2 - x^3\). The closure of \(\{\inner{f}\}\) contains every maximal ideal \(\inner{x - a, y- b}\) such that \(b^2 - a^3 = 0\), since such maximal ideals contain \(\inner{f}\).
\end{example}

Consider the ring \(A = \C[[x]]\), the ring of formal power series in \(x\). Then

\[\Spec(A) = \left\{\inner{0}, \inner{x}\right\}\]

which

\begin{align*}
    \overline{\set{\inner{0}}} &= \Spec(A) \\
    \overline{\set{\inner{x}}} &= \set{\inner{x}}
\end{align*}

On the other hand, \(\maxSpec(A)\) is a single (closed) point, which is the same as \(\Spec(\C)\).
