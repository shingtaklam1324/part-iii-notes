\section{Combinatorial group theory}

Combinatorial group theory is a sibling field to Geometric group theory. Both study infinite discrete groups.

\subsection{Free groups and presentations}

Let \(A = \{a_1, a_2, \dots\}\) be an \emph{alphabet}. A group \(F\) is \emph{free on \(A\)} if
\begin{enumerate}
    \item There is a map of sets \(A \to F\),
    \item for any group \(G\), and a map of sets \(A \to G\), there exists a unique group homomorphism \(F \to G\) such that
    % https://q.uiver.app/#q=WzAsMyxbMCwxLCJBIl0sWzEsMCwiRiJdLFsxLDEsIkciXSxbMCwxXSxbMSwyXSxbMCwyXV0=
    \[\begin{tikzcd}
        & F \\
        A & G
        \arrow[from=2-1, to=1-2]
        \arrow[from=1-2, to=2-2]
        \arrow[from=2-1, to=2-2]
    \end{tikzcd}\]
    commutes.
\end{enumerate}
This is a \emph{universal property}. As usual, this means that \(F\) is unique up to unique isomorphism. This shows that \(F\) is determined by \(A\), so we may write \(F = F(A)\).

However (as usual with definitions by universal property), we don't know if \(F(A)\) exists. We'll show this two different ways.

\textbf{1. Topologically:} Let
\[X = \bigvee_{a \in A}S^1\]
By the Seifert-van Kempen theorem,
\[\pi_1(X) \cong F(A)\]

\textbf{2. Combinatorially:} Let
\[A^* = \{\text{words in }A \sqcup A^{-1}\}\]
where \(A^{-1} = \{a_1^{-1}, \dots, a_n^{-1}\}\). For example,
\[1 = \emptyset, aa, aa^{-1}, aba^{-1}b^{-1}, a^{100}ba^{-100}b, \dots\]
A word is \emph{reducible} if it contains \(aa^{-1}\) or \(a^{-1}a\) as a subword for any \(a \in A\). Otherwise, it is \emph{reduced}. We can now define
\[F(A) = \left\{w \in A^* \text{ reduced}\right\}\]
The group operation is concatenation, followed by reduction. For example,
\[(abab^{-1})(b^2a) = abab^{-1}b^2a = ababa\]
Note that reduction terminates as each reduction step reduces the length. We won't check that this is well defined or associative. The identity element is \(1\), inverses is clear.

A \emph{presentation} consists of an alphabet \(A\), which we will call \emph{generators}, and a set \(R \sse F(A)\), which we will call \emph{relations}, and we write
\[\inner{A \mid R} = \inner{a_1, a_2, \dots \mid r_1, r_2, \dots}\]
This \emph{presents}  a group
\[G = \frac{F(A)}{\iinner{R}}\]
where \(\iinner{R}\) is the \emph{normal closure} of \(R\), i.e. the smallest normal subgroup of \(F(A)\) containing \(R\).

\begin{example}
    Some examples of presentations which we have seen:
    \begin{align*}
        \inner{a \mid a^n} &\cong \Z/n\Z \\
        \inner{r, s \mid r^n, s^2, srsr} &\cong D_{2n} \\
        \inner{A\mid} &\cong F(A) \\
        \inner{a, b \mid aba^{-1}b^{-1}} &\cong \Z^2 \\
        \inner{a_1, \dots, a_g, b_1, \dots, b_g \mid a_1b_1a_1^{-1}b_1^{-1}\cdots a_gb_ga_g^{-1}b_g^{-1}} &\cong \pi_1(\Sigma_g)
    \end{align*}
    where \(\Sigma_g\) is the compact orientable surface of genus \(g\).
\end{example}
As we see, presentations arise when we write down fundamental groups of spaces. In fact, all groups arise this way.
\begin{corollary}
    [of Seifert-van Kampen]
    For
    \[G = \inner{a_1, a_2, \dots \mid r_1, r_2, \dots}\]
    there exists a space \(X\) with \(\pi_1(X) = G\).
\end{corollary}

\begin{proof}
    First, start of with a wedge of circles, one for each \(a_i\). Also consider a disjoint union of discs, one for each \(r_i\). Attach the \(i\)-cell along its boundary, which is a loop in the wedge of circles.
\end{proof}

This is called the \emph{presentation complex} of \(G\). For example, if we have \(\Z^2 = \inner{a, b \mid aba^{-1}b^{-1}}\), then \(X = \T^2\) is the \(2\)-torus.

In 1911, Max Dehn posed the following problems.
\begin{enumerate}
    \item (Word problem) Given \(w \in A^*\), determine whether or not \(w = 1\) in \(G = \inner{A \mid R}\). That is, whether or not \(w \in \iinner{R} \sse F(A)\).
    \item (Conjugacy problem) Given \(G = \inner{A \mid R}\), \(u, v \in A^*\), determine whether or not \(u\) is conjugate to \(v\) in \(G\).
    \item (Isomorphism problem) Given \(G = \inner{A \mid R}, H = \inner{B \mid S}\), determine whether or not \(G\) is isomorphic to \(H\).
\end{enumerate}

\lec

\begin{remark}
    The conjugacy problem is stronger than the word problem, since \(w = 1\) if and only if \(w\) is conjugate to \(1\).

    Dehn was motivated by topology, but the problems asks for algorithms. We will often solve them using geometry.

    All three were \emph{un}solved in the 1950s, as all three problems are algorithmically undecidable. Nevertheless, positive solutions are known for many reasonable classes of groups.
\end{remark}

Let \(A = \{a_1, \dots, a_n\}\) be a finite alphabet.

\begin{example}
    [word problem in free groups]

    Let \(w \in A^*\). If \(w\) is reduced, then \(w = 1\) if and only if \(w = \emptyset\). Otherwise, \(w\) contains a subword \(aa^{-1}\) for some \(a \in A \cup A^{-1}\). Cancelling \(aa^{-1}\) produces a word \(w' \in A^*\), such that \(w = w'\) in \(F(A)\), and \(\ell(w') = \ell(w) - 2 < \ell(w)\). This terminates after finitely many steps. 
\end{example}

We can also solve the conjugacy problem for free groups.

\begin{definition}
    There is a natural action of \(\Z\) on \(A^*\) permuting words. That is,
    \[1\cdot a_1\cdots a_k = a_2a_3\cdots a_ka_1\]
\end{definition}

The elements of \(\Z \cdot w\) are called the \emph{cyclic conjugates} of \(w\). Note that all \(u \in \Z w\) are conjugate to \(w\). The orbits \(\Z \backslash A^*\) are called \emph{cyclic words}. A word is \emph{cyclically reduced} if every cyclic conjugate is reduced.

\begin{example}
    \(aba^{-1}\) is reduced, but not cyclically reduced as \(ba^{-1}a\) is not reduced.
\end{example}

Note that if \(w\) is reduced, but not cyclically reduced, then
\[w = aw'a^{-1}\]
for some \(a \in A \cup A^{-1}\). Note that \(w'\) is both conjugate to \(w\) and shorter than \(w\). Hence after finitely many iterations, we can assume that \(w\) is cyclically reduced.

\begin{lemma}
    [conjugacy problem in free groups] If \(u, v \in F(A)\) are cyclically reduced, then \(u\) is conjugate to \(v\) if and only if the corresponding cyclic words are the same.
\end{lemma}

\begin{proof}
    If \(u, v\) have the same cyclic words, then \(v\) is a cyclic conjugate of \(u\), which we have seen is a conjugate of \(u\).

    Conversely, suppose \(u = gvg^{-1}\). By induction on \(\ell(g)\), we can assume \(g = a \in A \cup A^{-1}\). From this it follows that either \(v = a^{-1}v'\), or \(v = v'a\), as \(v\) is cyclically reduced. That is, \(u = v'a^{-1}\) or \(u = av'\). In both cases, they are cyclic conjugates.
\end{proof}

\subsection{Historical case study}

Let's briefly think about the state of topology in the early 20th century. Poincar\'e knew that homology classifies the compact two-dimensional surfaces. This motivated the

\begin{conjecture}
    [Poincar\'e conjecture, version 1] Let \(M\) be a compact connected 3-manifold, with
    \[\HH_*(M) = \begin{cases}
        \Z & * = 0, 3 \\
        0 & \text{otherwise}
    \end{cases}\]
    Then \(M\) is homeomorphic to \(S^3\).
\end{conjecture}

Such a 3-manifold \(M\) is called a \emph{homology sphere}.

\begin{theorem}
    [Poincar\'e, 1904] There exists a three dimensional homology sphere \(P\), with
    \[\pi_1(P) \surj A_5\]
\end{theorem}

The moral is that: homology is not enough, we need use \(\pi_1\) as well.

\begin{conjecture}
    [Poincar\'e conjecture, version 2] Let \(M\) be a compact connected \(3\)-manifold, with \(\pi_1(M) = 1\). Then \(M\) is homeomorphic to \(S^3\).
\end{conjecture}

This was proven by Perelman in 2003. Returning to the original conjecture, in 1910 Dehn wanted to construct more homology spheres.

\begin{theorem}
    [Dehn, 1910] There are infinitely many non-homeomorphic 3-dimensional homology spheres.
\end{theorem}

\begin{remark}
    The isomorphism problem is exactly what is needed to distinguish these manifolds.
\end{remark}

\lec

Here is Dehn's construction. Consider the trefoil knot \(K \sse \R^3 \sse S^3\). Let \(N(K)\) be a regular open neighbourhood of \(K\), i.e. a thickening of \(K\). Let \(N = S^3 \setminus N(K)\). This is a compact 3-manifold with boundart \(\partial N \cong \T^2\).

Computing,
\[\HH_*(N) = \begin{cases}
    \Z & * = 0, 1 \\
    0 & \text{otherwise}
\end{cases}\]
and
\[\pi_1(N) \cong \inner{x, y, z \mid x^2 = y^3 = z}\]
This follows from the fact that \(K\) is a torus knot, and we can compute the \(\pi_1\) of the complement of a torus knot. Note that the abelianisation map
\[\pi_1(N) \to \HH_1(N) \cong \Z\]
sends \(z\) to \(6\), \(x\) to \(3\) and \(y\) to \(2\). Moreover, the boundary torus \(T\) has \(\pi_1(T) = \Z^2\), generated by \(xy\) and \(z\). Under the abelianisation map, \(xy\) is sent to \(5\).

We can glue a solid torus \(D^2 \times S^1\) to \(N\), by a homeomorphism on the boundary. Let \(\lambda, \mu\) be the corresponding loops on \(\T^2\). The resulting manifold \(M_\phi = N \cup_\phi T\) is closed. \(\pi_1(M_\phi)\) depends on \(g = \phi_*(\mu)\). By Seifert-van Kapmen, 
\[\pi_1(M_\phi) = \frac{\pi_1(N)}{\iinner{g}}\]
Similarly,
\[\HH_1(M_\phi) = \frac{\Z}{\inner{[g] \in \HH^1(N)}}\]
To produce a homology sphere, we need to choose \(\phi\) such that \(g = \phi_*(\mu) = 1\) in \(\HH^1(N)\).

If \(g = (xy)^az^b\), then in \(\HH^1(N)\) this is mapped to \(5a + 6b \in \Z\). Choose \(a = 6n + 5\), and \(b = -(5n + 4)\) for \(n \in \Z\). He constructs \(\phi_n\) such that
\[\phi_n(\mu) = g_n = (xy)^{6n+5}z^{-(5n+4)}\]
His family of manifolds
\[D_n = N \cup_{\phi_n} U\]
has
\[\pi_1(D_n) = \inner{x, y, z \mid x^2 = y^2 = z, (xy)^{6n+5} = z^{5n + 4}}\]
The remaining challenge is to prove the groups \(G_n = \pi_1(D_n)\) for \(n \ge 0\) are pairwise non-isomorphic.

This is the isomorphism problem! In particular,
\[g_n = g_m \implies g_n \text{ and }g_m\text{ are conjugate} \implies G_n \cong G_m\]
So we also need to solve the word and conjugacy problem in \(\pi_1(N)\).

\subsection{van Kampen diagrams}

\begin{definition}
    A map \(f : Y \to X\) of cell complexes is called \emph{combinatorial} if for all \(k \in \Z_{\ge 0}\), and every \(k\)-cell \(e^k\) of \(Y\), \(f\) maps the interior \(\Int(e^k)\) homeomorphically to the interior of a \(k\)-cell of \(X\).
\end{definition}

Consider a presentation \(G = \inner{a_i \mid r_j}\), and the associated presentation complex \(X\).

\begin{definition}
    A \emph{(singular) disc diagram} is a compact contractible \(2\)-complex \(D\), with an embedding \(D \inj \R^2\). A disc diagram \(D\) is \emph{over \(X\)} if it is equipped with a combinatorial map \(D \to X\).
\end{definition}

\begin{example}
    \begin{center}
        \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (1).jpg}
    \end{center}
\end{example}

Recall that \(X\) is given by a wedge of circles, with discs glued on for each relation. So the \(1\)-cells correspond to generators, \(2\)-cells go to relations (or cyclic conjugates, or inverses). With this:
\begin{itemize}
    \item every oriented \(1\)-cell of \(D\) is labelled with some \(a_i \in A\),
    \item so that each \(2\)-cell has boundary which is a cyclic conjugate of some \(r_j^{\pm 1}\).
\end{itemize}
Associated to each disc diagram \(D\), we have a \emph{boundary cycle}, which reads a (cyclic\footnote{or a word once we choose a base point.}) word \(w \in A^*\), which reduces to an element \(w' \in \iinner{r_j} \le F(A)\). To see this, \(D\) is contractible.

\(D\) is a \emph{van Kampen diagram for \(w\)}.

\lec

\begin{lemma}
    [van Kampen] If \(w \in \iinner{R}\), then there exists a van Kampen diagram for \(w\).
\end{lemma}

\begin{proof}
    Suppose \(w \in \iinner{R}\). Then \(w\) can be written as
    \[w = \prod_{i=1}^k h_ir_i^{\pm 1}h_i\]
    in \(F(A)\), where \(h_i \in F(A)\), and \(r_i \in R\). Now build a \emph{lollipop diagram} \(D_0\), which has boundary word \(w_0\), which is equal to \(w\) in \(F(A)\), but may not be reduced.

    \begin{center}
        \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (2).jpg}
    \end{center}

    If \(w_0\) is reduced, \(w = w_0\), and so we are done. Otherwise, \(w_0\) contains a cancelling pair, so
    \[w_0 = \cdots a a^{-1}\cdots\]
    for some \(a \in A \cup A^{-1}\).

    We can see that \(e_1, e_2\) share a vertex. There are two cases to consider:
    \begin{enumerate}
        \item if the \emph{origin} of \(e_1\) is the \emph{terminus} of \(e_2\), then the diagram \(D_0\) is a wedge \(D_1 \vee D'\). 
        \begin{center}
            \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (3).jpg}
        \end{center}
        Then \(D_1\) is a van Kampen diagram for \(w_1\), which is the result of cancelling \(a\) and \(a^{-1}\).
        \item if the origin of \(e_1\) is distinct from the terminus of \(e_2\), then we can fold the edges to get \(D_1\), 
        \begin{center}
            \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (4).jpg}
        \end{center}
        which has boundary word \(w_1\) as above.
    \end{enumerate}

    In either case, \(w_1 = \partial D_1\) is obtained from \(w_0\) by cancelling a pair. Therefore, we may proceeed by induction, and after finitely many repetitions, we construct a van Kampen diagram \(D_n\) such that \(w_n = \partial D_n\) is reduced, and \(w_n = w\) in \(F(A)\). Thus, \(w_n = w\) as words, and so \(D_n\) is a van Kampen diagram for \(w\).
\end{proof}

\begin{remark}
    The minimal number of \(2\)-cells in a van Kampen diagram of \(w\) is the minimal number of \(k\), such that \(w\) can be written as
    \[w = \prod_{i=1}^k h_ir_i^{\pm 1}h_i^{-1}\]
    This is called the \emph{area} of \(w\).
\end{remark}

\begin{example}
    Let \(G = \Z^2 = \inner{a, b \mid [a,b]}\). Consider \(w = a^n b^n a^{-n}b^{-n}\). This has van Kampen diagram

    \begin{center}
        \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (5).jpg}
    \end{center}

    In this case, \(\Area(D) = n^2\). We will show \(D\) is minimal, and so \(\Area(w) = n^2\).
\end{example}

\begin{definition}
    Let \(\mcP = \inner{A \mid R}\) be a finite presentation of a group \(G\). Define
    \begin{align*}
        \delta_\mcP : \N &\to \N \\
        \ell &\mapsto \max_{w \in \iinner{R}, \ell(w) = d}\Area(w)
    \end{align*}
    This is called the \emph{Dehn function.}
\end{definition}

\begin{remark}
    The word problem in \(\mcP\) if and only if \(\delta_\mcP\) is computable.
\end{remark}

\subsection{Cayley graphs}

A \emph{graph} is a \(1\)-dimensional cell complex. Throughout, let \(G\) be a group, with finite generating set \(S \sse G\).

\begin{definition}
    The \emph{Cayley graph} \(\Cay_S(G)\) is defined as follows:
    \begin{itemize}
        \item vertices \(V(\Cay_S(G)) = G\),
        \item edges \(E(\Cay_S(G))\) correspond bijectively with \(G \times S\). That is, we have an edge \(g \to gs\).
    \end{itemize}
\end{definition}

\end{example}

Note that the action of \(G\) on itself on the \emph{left} extends to an action of \(G\) on \(\Cay_S(G)\), sending an edge \(h \to hs\) to \(gh \to ghs\). Note the right action does not work, because of our definition of the Cayley graph.

\begin{remark}
    The action of \(G\) on \(\Cay_S(G)\) is free. That is, for all \(x \in \Cay_S(G)\), \(\Stab_G(x) = 1\).
\end{remark}

\begin{proposition}
    Let \(G = \inner{S \mid R}\), and let \(X\) be the corresponding presentation complex. Then there exists a \(G\)-equivariant isomorphism of graphs
    \[\Cay_S(G) \cong \widetilde{X}_{(1)}\]
    with the \(1\)-skeleton of the universal cover \(\widetilde X\) of \(X\)\footnote{and not the other way around.}.
\end{proposition}

\lec

\begin{proof}
    Consider the natural free action of \(G = \pi_1(X)\) on \(\widetilde X\), by deck transformations. The action is by combinatorial endomorphisms. In particular, it preserves the \(1\)-skeleton. So we have a free action of \(G\) on \(\widetilde{X}_{(1)}\), which sends vertices to vertices and edges to edges.

    The action of \(G\) on \(\widetilde X_{(0)}\) is free, and as \(X\) has only one vertex, transitive. Therefore, choosing a base vertex \(\widetilde v_0\), the orbit-stabiliser theorem provides a \(G\)-equivariant bijection
    \[G \to \Orb(\widetilde v_0) = \widetilde{X}_{(0)}\]
    sending \(g\) to \(g\vdot \widetilde v_0\). So this matches up the vertices as required.

    Next, let us match up the edges. For each \(s \in S\), let \(e_s\) be the corresponding edge of \(X\). Let \(\widetilde e_s\) be the unique lift of \(e_s\) to \(\widetilde{X}\), beginning at \(\widetilde v_0\). By the definition of the action of \(G\) on \(\widetilde{X}\), \(e_s\) ends at \(s \vdot \widetilde v_0\). Now an arbitrary edge \(\widetilde e\) of \(\widetilde X\) maps to some \(e_s\), under the covering map. Since egdes of \(X\) correspond to \(G\)-orbits of edges in \(\widetilde X\), it folloes that \(\widetilde e = g \vdot \widetilde e_s\) for some \(s \in S\). That is, \(\widetilde e\) is the edge from \(g\vdot \widetilde v_0\) to \(gs \vdot \widetilde v_0\). So it corresponds to an edge from \(g\) to \(gs\).

    This shows that the \(G\)-equivariant map \(G \to \widetilde{X}_{(0)}\) extends to a \(G\)-equivariant isomorphism of graphs as claimed.
\end{proof}

The next proposition deepens the relationship between generating sets and path connectedness.

\begin{proposition}
    Let \(\widetilde X\) be a path connected topological space, and suppose that \(G\) acts on \(\widetilde X\) by homeomorphisms. If \(U \sse \widetilde X\) is an open subset, such that \(G \vdot U = \widetilde X\), then the set
    \[S = \{g \in G \mid g\vdot U \cap U \ne \emptyset\}\]
    generates \(G\).
\end{proposition}

\begin{proof}
    Fix a base point \(\widetilde x_0 \in U\). Now for \(g \in G\), let \(\gamma : [0, 1] \to \widetilde X\) be a path from \(\widetilde x_0\) to \(g \vdot \widetilde x_0\). The set \(\{\gamma^{-1}(h \vdot U) \mid h \in G\}\) is an open cover of \([0, 1]\). So it has a finite subcover, \(\{\gamma^{-1}(U_1), \dots, \gamma^{-1}(U_n)\}\), where \(U_i = g_i\vdot U\). We may choose the indices so that
    \begin{itemize}
        \item \(\widetilde x_0 \in U_1\),
        \item \(\gamma^{-1}(U_i) \cap \gamma^{-1}(U_{i+1}) \ne \emptyset\) for all \(i\),
        \item \(g\vdot \widetilde x_0 \in U_n\).
    \end{itemize}
    Note that the \(g_i\) need not be unique. By definition, \(x_0 \in U \cap g_1 \vdot U\), and so \(g_1 \in S\). Similarly, if \(t_i \in \gamma^{-1}(U_i) \cap \gamma^{-1}(U_{i+1})\), then \(x_i = \gamma(t_i) \in g_i \vdot U \cap g_{i+1} \vdot U\). Thus,
    \[g_i^{-1}\vdot x_i \in U \cap g_i^{-1}g_{i+1}\vdot U\]
    and so \(s_i = g_i^{-1}g_{i+1} \in S\). Thus, \(g_n = s_{n-1}\cdots s_2s_1g_1\), is a finite product of elements of \(S\). Finally, \(g^{-1}g_n \in S\) similarly to the above, so \(g \in \inner{S}\) as required.
\end{proof}

\begin{example}
    Let \(\Gamma \sse \Isom(\R^2)\) be the symmetry group of the standard tiling of the plane by equilateral triangles. Let \(U\) be a thickened triangle. Using the proposition, we obtain a finite generating set of \(\Gamma\). In particular, \(\Gamma\) is generated by the reflections in the sides of a single triangle.

    In particular, this is not a covering space action, as it is not free.
\end{example}

\begin{definition}
    An action of \(G\) on \(\widetilde X\) by homeomorphisms is \emph{properly discontinuous} if for every compact \(K \sse \widetilde X\), the set
    \[\{g \vdot K \cap K\}\]
    is finite.

    The action is \emph{cocompact} if there exists \(K \sse \widetilde X\) compact, such that
    \[G \vdot K = \widetilde X\]
    
    \(\widetilde X\) is \emph{locally compact} if for every neighbourhood \(U\) of \(x\), there exists an open neighbourhood \(V \sse U\) of \(x\), such that \(\widetilde V \sse U\) is compact.
\end{definition}

\begin{corollary}
    If \(G\) acts on \(\widetilde X\) properly discontinuously and cocompactly, and \(\widetilde X\) is path connected and locally compact, then \(G\) is finitely generated.
\end{corollary}

\lec

\begin{proof}
    Let \(K \sse \widetilde X\) be compact, such that \(G \vdot K = \widetilde X\). By local compactness, we may find an open \(U\) such that \(K \sse U\), and \(\overline U\) is compact. In particular, \(G \vdot U = \widetilde X\), and the set
    \[S = \{g \in G \mid g\vdot U \cap U \ne \emptyset\} \sse \{g \mid g \vdot  \overline U \cap \overline U \ne \emptyset\}\]
    But the right hand side is finite, so \(S\) is finite. By the proposition, \(S\) generates \(G\).
\end{proof}

\begin{corollary}
    If \(X\) is compact, locally compact and has a universal cover \(\widetilde X\), then \(\pi_1(X)\) is finitely generated.
\end{corollary}

\subsection{The Schwarz-Milnor lemma}

Cayley graphs are not just combinatorial. They admit a natural metric, called the \emph{word metric}.

\begin{definition}
    [word metric] Let \(S\) generate \(G\). Define
    \[\ell_S(G) = \min\{n \mid g = \prod_{i=1}^n s_i^{\pm 1}, s_i \in S\}\]
    This defines a metric
    \[d_S(g, h) = \ell_S(g^{-1}h)\]
    called the \emph{word metric} associated to \(S\).
\end{definition}

The word metric is invariant under the \emph{left} \(G\) action on itself. That is,
\[d_S(\gamma g, \gamma h) = d_S(g, h)\]
However, it is, in general, not right invariant.

\begin{example}
    \(G = \Z^2 = \inner{a} \oplus \inner{b}\). Then the word metric is just the \(\ell_1\)-metric.
\end{example}

\begin{remark}
    The word metric extends naturally to a left invariant metric on \(\Cay_S(G)\), in which the interior of each edge is locally isometric to \((0, 1)\). That is, the path metric.
\end{remark}

\begin{lemma}
    Suppose \(S, T\) are finite  generating sets for \(G\). Then there exists constants \(C, C" \ge 1\) such that
    \[\frac{1}{C}d_T \le d_S \le C' d_T\]
\end{lemma}

\begin{proof}
    Let \(C = \max_{s \in S}\ell_T(s)\). Then for any \(g\in G\),
    \[\ell_T(g) \le C\ell_S(g)\]
    by induction.
\end{proof}

That is, for finitely generated groups, the word metric is well defined, up to bi-Lipschitz equivalence.

\begin{definition}
    [quasi-isometry] A function\footnote{It does not have to continuous.} \(f : X \to Y\) between metric spaces is a \emph{quasi-isometric embedding} if there are constants \(C \le 1\), \(D \ge 0\), such that
    \[\frac{1}{C}d(x, x') - D \le d(f(x), f(x')) \le Cd(x, x') + D\]
    for all \(x, x' \in X\).

    If in addition, there exists a constant \(K\) such that for every \(y \in Y\), there exists \(x \in X\) such that \(\dd(f(x), y) \le K\), then \(f\) is called a quasi-isometry, and we write \(X \qi Y\).
\end{definition}

\begin{remark}
    On examples sheet 1, we have that \(\qi\) is an equivalence relation.
\end{remark}

\begin{example}
    Every bounded metric space is quasi-isometric to a point.
\end{example}

\begin{definition}
    [proper]
    A metric space \(X\) is \emph{proper} if closed balls in \(X\) are compact.
\end{definition}

\begin{definition}
    [geodesic]
    A \emph{geodesic} in \(X\) is an isometric embedding \(\gamma : [a, b] \to X\). The metric space \(X\) is \emph{geodesic} if every pair of points is joined by a geodesic.
\end{definition}

\begin{theorem}
    [Schwarz-Milnor]

    Suppose \(X\) is a proper geodesic metric space. Let \(G\) acts on \(X\) properly discontinuously and cocompactly by isometries. Then \(G\) is finitely generated, and
    \[X \qi (G, d_S)\]
    for any finite generating set \(S\) of \(G\).
\end{theorem}

\begin{proof}
    Fix a base point \(x_0 \in X\). Let \(B = \overline{B}(x_0, K) \sse X\) be a closed ball, such that \(G \vdot B = X\). By properness and proper discontinuity, the set
    \[\{g \in G \mid d(x_0, g(x_0)) \le 3K\}\]
    is finite. Therefore, there exists \(\epsilon > 0\), such that 
    \[d(x_0, g(x_0)) < 2K + \epsilon \iff d(x_0, g(x_0)) \le 2K\]
    Moreover, in this case, \(g B \cap B \ne \emptyset\).

    \lec

    If \(U = B(x_0, K + \epsilon/2)\), then
    \[S  = \{g \vdot U \cap U \ne \emptyset\} = \{g \vdot B \cap B \ne \emptyset\}\]
    Since \(B\) is compact, \(S\) is finite, since the action is properly discontinuous. But \(S\) is a generating set for \(G\).

    Since the word metric for any two finite generating sets are bi-Lipschitz, we may prove the result for the \(S\) above. Consider the map \(f : G \to X\), \(f(g) = g \vdot x_0\). We claim that this is a quasi-isometry. \(f\) is quasi-surjective, since \(G\vdot B = X\). It remains to prove that \(f\) is a quasi-isometric embedding. That is, we want upper and lower bounds on \(d(x_0, g\vdot x_0)\) in terms of \(\ell_S(g)\).

    For the upper bound, take \(C = \max_{s \in S}d(x_0, s\vdot x_0)\). Then
    \[d(x_0, g\vdot x_0) \le C\ell_S(g)\]
    for any \(g \in G\), using the triangle inequality.

    For the lower bound, consider a geodesic \(\gamma : [0, d(x_0, g\vdot x_0)] \to X\) from \(x_0\) to \(g\vdot x_0\). Choose a dissection of \([0, d(x_0, g\vdot x_0)]\)
    \[0 = t_0 < t_1 < \cdots < t_n < t_{n+1} = d(x_0, g\vdot x_0)\]
    with
    \[\frac{\epsilon}{2} \le \abs{t_i - t_{i+1}} < \epsilon\]
    for \(0 \le i \le n-1\). Note we can make it so that \(\abs{t_n - t_{n+1}} < \epsilon\), but we may not have the lower bound.

    Since \(G \vdot B\) covers \(X\), for \(1 \le i \le n\), there exists \(g_i \in G\) such that \(\gamma(t_i) \in g_i \vdot B\). Set \(g_0 = 1\) and \(g_{n+1} = g\). Then \(\gamma(t_i) \in g_i\vdot B\) for all \(i\). For each \(i\),
    \[d(g_i(x_0), g_{i+1}(x_0)) < 2K + \epsilon\]
    by the triangle inequality. Therefore, \(g_i^{-1}g_{i+1} \in \{h \vdot U \cap U \ne \emptyset\} = S\). Hence \(\ell_S(g) \le n+1\). Furthermore,
    \[\abs{t_i - t_{i-1}} \ge \epsilon/2\]
    for all \(1 \le i \le n\), so \(d(x_0, g \vdot x_0) \ge n\epsilon/2\). Combining these,
    \[\ell_S(g) \le n + 1 \le \frac{2}{\epsilon}d(x_0, g\vdot x_0) + 1\]
    We can rearrange this to get the lower bound.
\end{proof}

\begin{example}
    Recall the two Cayley graphs of \(\Z\), with generating sets \(\{1\}\), and \(\{2, 3\}\) respectively.

    The Schwartz-Milnor says that these are both quasi-isometric to \(\Z\) with an appropriate word metric. So they are quasi-isometric. More generally, for any finitely generated group \(G\), the Cayley graphs of any two finite generating sets are quasi-isometric.
\end{example}

\begin{corollary}
    If \(G\) is finitely generated, \(H\) is a subgroup with finite index in \(G\). Then \(H\) is finitely generated, and \(H\) is quasi-isometric to \(G\).
\end{corollary}

\begin{proof}
    \(H\) acts on \(\Cay_S(G)\). The action is cocompact as \(H\) has finite index. So it satisfies the Schwartz-Milnor lemma.
\end{proof}

\begin{example}
    Let \(\Sigma_2\) be the closed orientable surface of genus \(2\), and \(G = \pi_1(\Sigma_2)\). Choose a Riemannian metric \(g\) on \(\Sigma_2\) of constant curvature \(-1\).

    This pulls back to a Riemannian metric on its universal cover \(\widetilde \Sigma_2\). By a classical theorem of differential geometry, \(\widetilde \Sigma_2\) is isometric to the hyperbolic plane \(\bb H^2\). Moreover, the action of \(G\) on the \(\bb H^2\) by isometries, and properly discontinuously. The action is cocompact as the quotient is \(\Sigma_2\), which is compact. So by the Schwartz-Milnor lemma, \(\pi_1(\Sigma_2)\) is quasi-isometric to \(\bb H^2\).
\end{example}

\subsection*{Reduced words}

A word \(w \in A^*\) is reduced if and only if the corresponding edge path \(w : I \to X_n\) is locally injective. In turn, this holds if and only if the corresponding edge path \(w : I \to T_n\) is locally injective. This is because an edge path can only fail to be locally injective at a vertex.

Clearly, the shortest path in \(T_n\) from \(1\) to \(g \in F_n\) is injective. In particular, locally injective. So every element of \(F_n\) is represented by a reduced word.

The fact that this representative is unique follows from the next lemma.

\begin{lemma}
    If \(T\) is a tree, and \(\gamma: I \to T\) is a locally injective (edge) path, then \(\gamma\) is injective.
\end{lemma}

\begin{proof}
    Suppose not. Let \(\gamma : [a, b] \to T\) be the shortest counterexample. In particular, \(\gamma(a) = \gamma(b)\), and \(\gamma\) is injective on \((a, b)\). So \(\gamma\) descends to an injective map \(S^1 \to T\). But \(T\) is a tree. Contradiction.
\end{proof}

Similarly, if \(g \in F_n\) is shortest such that \(g\) is represented by distinct reduced words \(w_1, w_2\), then we get an embedding \(S^1 \inj T\). Hence the reduced word is unique.

For \(g \in F_n\), write \([1, g]\) for the unique injective edge path from \(1\) to \(g\).

\subsection*{Subgroups of free groups}

\begin{proposition}
    If \(X\) is a (connected) graph, then \(\pi_1(X)\) is free.
\end{proposition}

\begin{proof}
    [Proof when \(X\) has countably many cells] Let \(T \sse X\) be a maximal tree, and let \(\{e_1, e_2, \dots\}\) be the edges in \(X\) and not \(T\). Let \(X_N = T \cup \{e_1, \dots, e_N\}\). With this,
    \[X = \bigcup_{n \ge 1}X_n\]
    Pick a base vertex \(v_0 \in T\). For each \(e_i\), let \(\alpha_i\) be the illustrated loop.

    \begin{center}
        \includegraphics[scale=0.1]{diagrams/2024_02_20 17_55 Office Lens (17).jpg}
    \end{center}

\lec

    Note 
    \[X_{n+1} = X_n \cup e_{n+1} = X_n \cup_{Y_{n+1}} (S^1 \cup I)\]

    By Seifert-van Kampen,
    \[\pi_1(X_{n+1}) = \pi_1(X_n) * \inner{\alpha_{n+1}}\]
    Thus, by induction, \(\pi_1(X_n)\) is free for all \(n\), and generated by \(\alpha_1, \dots, \alpha_n\). When \(X\) is countably infinite, note that every (edge) loop \(\gamma \sse X\) is contained in \(X_n\) for some \(n\). Thus, \(\pi_1(X)\) is generated by \(\{\alpha_1, \alpha_2, \dots\}\).

    By the universal property of free groups, we have a surjection
    \[\eta : F_\infty = \inner{\alpha_1, \dots} \to \pi_1(X)\]
    Suppose \(\gamma\) is a loop representing an element of \(\ker(\eta)\). As before, \(\gamma\) is contained in \(X_n\) for some \(n\). So \(\gamma\) is in the kernel of the map
    \[\inner{\alpha_1, \dots, \alpha_n} \to \pi_1(X_n) \to \pi_1(X)\]
    The first map is an isomorphism, so \(\gamma \in \ker(\pi_1(X_n) \to \pi_1(X))\).

    Since \(X_n\) is a retract\footnote{i.e. the inclusion \(X_n \to X\) has a left inverse \(r : X \to X_n\)} of \(X\), every loop which is null-homotopic in \(X\), is null-homotopic in \(X_n\). So \(\gamma = 1\) in \(\pi_1(X_n) = \inner{\alpha_1, \dots, \alpha_n} \le F_\infty\).
\end{proof}

\begin{corollary}
    If \(G\) acts on a tree \(T\) freely, then \(G\) is free.
\end{corollary}

\begin{proof}
    The action of \(G\) on \(T\) is a \emph{covering space action}. Since \(T\) is simply connected, \(X = G \backslash T\) is a graph, with universal cover \(T\), and \(G = \pi_1(X)\) is free.
\end{proof}

\begin{corollary}
    [Nielsen-Schreier] Any subgroup of \(H \le F_n\) is free.
\end{corollary}

\begin{proof}
    Let \(T = T_n\) be the Cayley tree of \(F_n\). Then \(F_n\) acts on \(T\) freely, and so \(H\) acts freely on \(T\). By the previous corollary, \(H\) is free.
\end{proof}

\begin{remark}
    The choice of generating set comes from the choice of a maximal tree in the proposition.
\end{remark}

\begin{definition}

\begin{proof}

Because the edge \(t\) appears in each rectabgle, and nowhere else, the rectangular \(2\)-cells in \(D\) are arranged in strips, which we call \(t\)-corridors.

    \textbf{diagram}

    Since the boundary word is \(\gamma\), which is contained in \(X_A\). Therefore, we can't have any \(t\) on the boundary, so all of the \(t\)-corridors are annuli. Look at an \emph{inner most disc} \(D_0\) bounded by a \(t\)-corridor.

    \textbf{diagram}

    Since \(D_0\) is contained in a \(t\)-corridor, it is contained in \(X_A\) or \(X_B\). Without loss of generality (proof is symmetric), \(D_0 \sse X_A\). Going around the \(t\)-corridor, we get a cyclic word \(\delta\) in \(\Sigma \cup \Sigma^{-1}\). In particular, \(i(\delta)\) is the inner loop, \(j(\delta)\) is the outer loop. \begin{definition}

\subsection{Bass-Serre tree}

The main theorem of the subject is due to Serre, although we adopt a topological approach, due to Scott and Wall.

\begin{theorem}
    [Serre, the fundamental theorem of Bass-Serre theory] Let \(\mcG\) be a graph of groups, with connected underlying graph \(\Gamma\). Let \(G = \pi_1(\mcG)\). Then \(G\) acts on a tree \(T\), such that
    \[\mcG \cong G \backslash T\]
\end{theorem}

\(T\) is called the \emph{Bass-Serre tree} of \(\mcG\).

\begin{remark}
    Letting \(G\) act on a tree \(T\) is equivalent to cutting \(G\) into pieces. The theorem says that \(\mcG\) has a ``universal cover'' \(T\), on which \(G = \pi_1(\mcG)\) acts, and we recover \(\mcG\) as the quotient. 
\end{remark}

\begin{definition}
    [loop]
    Fix a base vertex \(v_0 \in V_\Gamma\). Consider an element
    \[w = g_0t_1^{\pm 1}\cdots g_{k=1}t_k^{\pm 1}g_k \in \left(\bigstar_{v \in V_\Gamma}G_v\right) * F(E_\Gamma)\]

    \begin{enumerate}[(i)]
        \item \(v_0 = v_k\), which is also the base vertex we fixed at the start of the definition.
        \item the path \(e_1^\pm 1\cdots e_k^\pm 1\) is a loop in \(\Gamma\) based at \(v_0\),
        \item ``if it goes'' \(t_ig_i\), then \(v_i = \tau(e_i)\). On the other hand, ``if it goes'' \(t_i^{-1}g_i\), then \(v_i = \iota(e_i)\).
    \end{enumerate}
\end{definition}

\[t_e\iota_e(G_e)t_e^{-1} = \tau_e(G_e)\]

        \item \(t_e\iota_e(h)t_e^{-1}\) for \(h \in G_e\), or
        \item \(t_e^{-1}\tau_e(h)t_e\) for \(h \in G_e\).

\end{definition}

\begin{theorem}
    [criterion for FA]

    Let \(G\) be a group, and suppose \(S = \{s_1, \dots, s_n\}\) is a generating set. If
    \begin{enumerate}[(i)]
        \item \(s_i\) has finite order for all \(i\),
        \item for all \(i, j\), either \(s_is_j\) or \(s_js_i\) has finite order.
    \end{enumerate}
    Then \(G\) has property FA.
\end{theorem}

\begin{proof}
    Suppose \(G\) acts on a tree \(T\). Let \(T_i = \Fix(s_i)\). Since \(s_i\) has finite order, \(T_i\) is non-empty. Since at least one of \(s_is_j, s_js_i\) has finite order, \(T_i \cap T_j\) is non-empty for all \(i, j\). Hence by the Helly property,
    \[\bigcap_{i=1}^n T_i \ne \emptyset\]
    But this is the set of global fixed points of \(G\).
\end{proof}

Let \(\bb H^2\) denote the hyperbolic plane. Recall we have the disc model and the upper half plane model, both contained in \(\C\).

\textbf{diagram}

We will write \(\ell^+ = \{iy \mid y > 0\}\) in the upper half plane. In this case, if \(s > t\), then
\[d(is, it) = \int_t^s \frac{\dd y}{y} = \log(\frac{s}{t})\]
One more useful fact is a special case of the Gauss-Bonnet theorem.

\begin{proposition}
    [Gauss-Bonnet for triangles] if \(\Delta \sse \bb H^2\) is a geodesic triangle, with interior angles \(\alpha, \beta, \gamma\), then
    \[\Area(\Delta) = \pi - (\alpha + \beta + \gamma)\] 
\end{proposition}

In particular, \(\alpha + \beta + \gamma < \pi\).

\begin{corollary}
    If \(P \sse \bb H^2\) is a geodesic \(n\)-gon, with interior angles \(\alpha_i\), then
    \[\Area(P) = (n-2)\pi - \sum_i \alpha_i\]
\end{corollary}

Recall that \(\Isom^+(\bb H^2) \cong \PSL(2, \R)\), acting on the upper half plane model by M\"obius transformations.

\begin{definition}
    [Fuchsian group]
    If \(\Gamma \le \PSL(2, \R)\) is a subgroup which acts properly discontinuously on \(\bb H^2\), then \(\Gamma\) is called a \emph{Fuchsian group}.
\end{definition}

We can also think of them as the discrete subgroups of \(\PSL(2, \R)\). Some basic facts of \(\PSL(2, \R)\):

\begin{proposition}
    \begin{enumerate}[(i)]
        \item The action of \(\PSL(2, \R)\) on \(\bb H\) extends continuously to \(\overline{\bb H}^2\), which is \(\bb H^2 \cup \partial \bb H^2\).
        \item \(\PSL(2, \R)\) is transitive on triples of distinct points on \(\R \cup \{\infty\}\),
        \item if \(\phi \in \PSL(2, \R)\) and fixes any three distinct points in \(\overline{\bb H}^2\), then \(\phi = \id\). 
    \end{enumerate}
\end{proposition}

\begin{corollary}
    [classification of (orientation preserving) isometries of \(\bb H^2\)] Suppose \(\phi \in \Isom^+(\bb H^2)\). Then one of the following holds:
    \begin{enumerate}[(i)]
        \item \(\phi\) fixes a point in \(\bb H^2\), which is unique unless \(\phi = \id\).
        \item \(\phi\) fixes a unique point in \(\partial \bb H^2\),
        \item \(\phi\) preserves a unique geodesic in \(\bb H^2\), which it translates a positive distance.
    \end{enumerate}
    In (i), \(\phi\) is elliptic, in (ii), \(\phi\) is parabolic, and in (iii), \(\phi\) is hyperbolic.
\end{corollary}

\begin{remark}
    If \(\Gamma\) is a Fuchsian group, \(\phi\) is elliptic, then \(\phi\) must have finite order. 
\end{remark}

\lec

\begin{proof}
    Recall that \(\phi : \bb H^2 \to \bb H^2\) extends continuously to a homeomorphism \(\phi : \overline{\bb H}^2 \to \overline{\bb H}^2\). By Brouwer's fixed point theorem, \(\Fix(\phi) \sse \overline{\bb H}^2\) is non-empty. We saw that if \(\phi\) has at least three fixed points, then \(\phi= \id\), so we can consider it case by case.

    \begin{enumerate}
        \item \(\Fix(\phi) = \{\xi\} \sse \overline{\bb H}^2\).
        \begin{enumerate}[(a)]
            \item If \(\xi \in \bb H^2\), then \(\phi\) is elliptic.
            \item If \(\xi \in \partial \bb H^2\), then \(\phi\) is parabolic.
        \end{enumerate} 
        \item \(\Fix(\phi) = \{\xi^+, \xi^-\}\).
        \begin{enumerate}[(a)]
            \item If \(\xi^+ \in \bb H^2\) (without loss of generality), we get a unique geodesic from \(\xi^+\) to \(\xi^-\). \(\phi\) preserves the geodesic \(\Ico{\xi^+, \xi^-}\). But then there is (at least) thre fixed points. So \(\phi = \id\).
            \item If \(\xi^+, \xi^- \in \partial\bb H^2\), then again we have a uique geodesic from \(\xi^+\) to \(\xi^-\), and \(\phi\) preserves it. Since \(\phi\) has two fixed points, \(\phi\) must act on the geodesic by a translation by a positive distance.
        \end{enumerate}
    \end{enumerate}
\end{proof}

When \(\phi\) is hyperbolic, we call the geodesic it preserves its \emph{axis}.

\subsection{Examples of Fuchsian groups}

Recall \(\Gamma \le \Isom^+(\bb H^2)\) is \emph{Fuchsian} if the action of \(\Gamma\) on \(\bb H^2\) is properly discontinuous. In particular, for all \(x \in \bb H^2\), \(\Stab_\Gamma(x)\) is finite.

Lets start with some easy examples.

\begin{example}
    Consider the disc model. The metric is radially symmetric, and so all rotations about \(0\) are isometries. In particular,
    \[z \mapsto e^{2\pi i/n}z\]
    is an isometry, generates \(\Z/n\Z \le \Isom^(\bb H^2)\).

    In fact, any elliptic isometry is conjugate to this one.
\end{example}

\begin{example}
    Now consider the upper half plane model. Consider the map \(z \mapsto \lambda z\), for any \(\lambda \in \R_{> 1}\). This is an element of \(\Isom^+(\bb H^2)\). The axis is \(\ell^+\). This gives \(\Z \cong \inner{\phi} \le \Isom^+(\bb H^2)\).

    In fact, any elliptic isometry is conjugate to this one.
\end{example}

\begin{example}
    Define \(\psi(z) = z + 1\). This is an isometry of \(\bb H^2\). This gives a parabolic isometry, where the fixed point is \(\infty\). This gives \(\Z \cong \inner{\psi} \le \Isom^+(\bb H^2)\).

    In fact, any parabolic isometry is conjugate to this one.
\end{example}

These examples are called \emph{elementary}. There's one more elementary example

\begin{example}
    Consider upper half plane. Let \(s_1\) be rotation by \(\pi\) about \(i\), and \(s_2\) be rotation by \(\pi\) about \(2i\). Then we get
    \[\inner{s_1, s_2} \cong D_\infty\]
\end{example}

\begin{example}
    Let \(\Sigma_g\) be a closed orientable surface of genus \(g\), with \(g \ge 2\). In this case, \(\widetilde \Sigma_g\) is isometric to \(\bb H^2\). Then \(\pi_1(\widetilde \Sigma_g)\) is Fuchsian.
\end{example}

\begin{definition}
    Let \(p, q, r \in \Z_{\ge 1}\). The \emph{\((p,q,r)\)-triangle group} is defined by the presentation
    \[\Gamma(p,q,r) = \inner{a,b,c \mid a^p, b^q, c^r, abc} = \inner{a, b \mid a^p, b^q, (ab)^{-r}}\]
\end{definition}

From our criterion for FA, \(\Gamma(p, q, r)\) has property FA. Thus, it does not split, and so we can't use the techniques we have developed so far.

Is \(\Gamma(p,q,r)\) non-trivial? infinite? and so on?

\begin{example}
    \(\Gamma(2,3,1) = 1\).
\end{example}

However, many interesting examples arise from Poincar\'e's polygon theorem.

\begin{theorem}
    [Poincar\'e's polygon theorem] If \(p^{-1} + q^{-1} + r^{-1} < 1\), then \(\Gamma(p, q, r)\) is an infinite Fuchsian group.
\end{theorem}

\begin{remark}
    The converse is morally true. That is, the other cases are all finite or non-Fuchsian.
\end{remark}

\begin{proof}
    We start with a geodesic triangle \(\Delta \sse \bb H^2\) with interior angles \(\pi/p, \pi/q, \pi/r\).

\lec

    \textbf{diagram}

    Let \(\alpha\) denote rotation about \(u\), with angle \(2\pi/p\); \(\beta\) about \(v\), with angle \(2\pi/q\) and \(\gamma\) about \(w\), with angle \(2\pi/r\). Note all of these are \emph{anticlockwise}.

    Let \(G = \inner{\alpha, \beta,\gamma} \le \Isom^+(\bb H^2)\). Clearly \(\alpha^p = \beta^q = \gamma^r = 1\). Next, we show \(\alpha\beta\gamma = 1\).

    \textbf{diagram}

    We see that \(\beta(w) = \alpha^{-1}(w) = w'\). Hence \(\alpha\beta\gamma(w) = \alpha\beta(w) = w\). Similarly, \(\gamma(u) = \beta^{-1}(u)\), and so \(\alpha\beta\gamma(u) = \alpha\beta\beta^{-1}(u) = \alpha(u) = u\). Hence by the classification of orientation preserving isometries of \(\bb H^2\), it fixes two distinct points in \(\mathbb H^2\) and so it is trivial.

    Hence we have a surjective homomorphism \(f : \Gamma(p, q, r) \surj G\), sending \(a\) to \(\alpha\) and so on. We will show that \(f\) is an isomorphism. Let \(r_\ell\) denote reflection in the line \(\ell\), and \(Q = \Delta \cup r_\ell(\Delta)\).

    \textbf{diagram}

    Define
    \[\widetilde Q  = \frac{\Gamma \times Q}{\sim}\]
    where \(\sim\) is the relation given by \((gc, x) \sim (g, c(x))\) for \(x \in m\), and \((gb, y) \sim (g, b(y))\) for \(y \in n'\). Next, define the \emph{development map}
    \begin{align*}
        F : \widetilde Q &\to \bb H^2 \\
        F(g, x) &= f(g)x
    \end{align*}
    Note \(\widetilde Q\) is a complete geodesic metric space, via the path metric, and \(F\) is a local isometry, sending (sufficiently small) open balls in \(\widetilde Q\) isometrically to small open balls in \(\bb H^2\). In fact, \(F\) is an isometric embedding.

    Indeed, if \(x, y \in \widetilde Q\), and \([x, y]\) is a geodesic, then \(F([x, y])\) is a local geodesic\footnote{i.e. locally it is a geodesic.} from \(F(x)\) to \(F(y)\). But local geodesics in \(\bb H^2\) are global geodesics. So \(d(F(x), F(y)) = d(x, y)\). Next, we prove that \(F\) is surjective. \(\im(F)\) is open, since it sends small open balls to small open balls. On the other hand, \(\widetilde Q\) is complete, and hence so is \(\im(F)\). But complete subsets of a metric space are closed, and so \(\im(F)\) is closed. Thus, by connectedness, \(F\) is an isometry.

    So \(\widetilde Q\) is isometric to \(\bb H^2\), and the action of \(\Gamma\) on \(\widetilde Q\) is properly discontinuous by construction, so \(\Gamma\) is Fuchsian. Since \(Q\) is compact, and \(F\) us surjective, \(\Gamma\) must be infinite.
\end{proof}

\begin{remark}
    It follows from the construction of \(\widetilde Q\) that only \(\Gamma \cdot u, \Gamma \cdot v, \Gamma \cdot w\) has non-trivial stabiliser. Moreover, \(\Stab(u) = \inner{a}, \Stab(v) = \inner{b}\) and \(\Stab(w) = \inner{c}\).

    \(Q\) is called a \emph{fundamental domain} for the action of \(\Gamma\) on \(\bb H^2\).
\end{remark}

\subsection{Centres and Dehn's examples}

\begin{lemma}
    Suppose \(1/p + 1/q + 1/r < 1\). If \(g \in \Gamma(p, q, r)\), and the order of \(g\) is finite, then \(g\) is in the conjugate of one of \(\inner{a}, \inner{b}, \inner{c}\).
\end{lemma}

\begin{proof}
    We saw that finite order elements of \(\bb H^2\) fix a point in \(\bb H^2\). If \(g \ne 1\), then the fixed point \(z\) must be in the orbit of one of \(u, v, w\). Say (without loss of generality) \(z = hu\). So \(ghu = hu\), and so \(h^{-1}gh \in \Stab(u) = \inner{a}\).
\end{proof}

\begin{proposition}
    If \(\Gamma\) is a non-elementary Fuchsian group, then \(Z(\Gamma) = 1\).
\end{proposition}

\begin{proof}
    Suppose \(\gamma \in Z(\Gamma) \setminus 1\). Consider \(\Fix(\gamma) \sse \overline{\bb H}^2\). Note that for \(g \in \Gamma, x \in \Fix(\gamma)\), \(gx = g\gamma x = \gamma gx\), and so \(gx \in \Fix(\gamma)\).

    \lec

    Now we need to do some case analysis:
    \begin{itemize}
        \item if \(\gamma\) is elliptic, then \(\Fix(\gamma) = \{x\} \sse \bb H^2\). Without loss of generality, \(x = 0\) in the disc model \(\bb D \sse \C\). From this,
        \[\Stab_{\Isom^+(\bb H^2)}(0) = \{z \mapsto e^{i\theta}z\}\]
        By proper discontinuity, \(\Gamma\) is a subgroup of the above, and so it is a finite cyclic group.
        \item if \(\gamma\) is parabolic, then without loss of generality \(\Fix(\gamma) = \{\infty\}\) in the upper half plane model. A direct computation shows that
        \[\Stab_{\Isom^+(\bb H^2)}(\infty) = \{z \mapsto az + b\}\]
        For \(\gamma\) to be the only fixed point, necessarily \(a = 1\), and so \(\gamma(z) = z + c\) for some \(c \in \R\) non-zero. But \(g\) commutes with \(\gamma\) only if \(a = 1\), and so
        \[\Gamma \le \{z \mapsto z + b \mid b \in \R\}\]
        Any discrete subgroup of \(\R\) is isomorphic to \(\Z\).
        \item if \(\gamma\) is hyperbolic, without loss of generlity \(\Fix(\gamma) = \{0, \infty\}\) in the upper half plane model. So \(\Gamma\) acts by isometries \(\Axis(\gamma) = \ell^+\), and so \(\Gamma \cong \Z\) or \(D_\infty\) by proper discontinuity.
    \end{itemize}
\end{proof}

We can now analyse Dehn's examples. Recall
\[G_n = \inner{x,y,z \mid x^2 = y^3 = z, (xy)^{6n+5} = z^{5n+4}}\]
for \(n \ge 0\). Note that \(z \in Z(G_n)\). Let 
\(\Gamma_n = \frac{G_n}{\inner{z}} = \inner{x, y \mid x^2, y^3, (xy)^{6n+5}} = \Gamma(2, 3, 6n+5)\). Therefore, \(\Gamma_n\) is a Fuchsian triangle group if \(n \ge 1\), and so \(Z(\Gamma_n) = 1\). Hence \(Z(G_n) = \inner{z}\). Therefore, if \(\phi : G_m \to G_n\) is an isomorphism, then \(\phi(Z(G_m)) = Z(G_n)\), and so
\[\Gamma_m = \frac{G_m}{Z(G_m)} \cong \frac{G_n}{Z(G_n)} = \Gamma_n\]
But the order of torsion elements in \(\Gamma_n\) are the divisors of \(2, 3, 6n+5\). Hence if \(\Gamma_m \cong \Gamma_n\), we must have that \(m = n\). We have proven:

\begin{theorem}
    [Dehn] There are infinitely many non-homeomorphic 3-dimensional homology spheres.
\end{theorem}

\section{Hyperbolic groups}

The goal is to define a notion of coarse hyperbolic geometry. This is something which looks like hyperbolic geometry that is invariant under quasi-isometry.

\subsection{Hyperbolic metric spaces}

Let \(X\) be a geodesic metric space. A \emph{geodesic triangle} is a triple of geodesics
\[\Delta = [x, y] \cup [y, z] \cup [z, x]\]

For \(A \sse X\), let
\[N_\delta(A) = \{y \in X \mid \exists x \in A, d(x, y) \le \delta\} = \bigcup_{x \in A}B_\delta(x)\]
be its (closed) \(\delta\)-neighbourhood.

\begin{definition}
    Let \(\delta \ge 0\). A geodesic triangle \(\Delta\) is \emph{\(\delta\)-slim} if the \(\delta\)-neighbourhood of any two sides cover the third side. So
    \[[x, y] \sse N_\delta([x, z] \cup [y, z])\]
    and so on.
\end{definition}

\begin{definition}
    \(X\) is called \emph{\(\delta\)-hyperbolic} if every geodesic triangle \(\Delta \sse X\) is \(\delta\)-slim. We also say \(X\) is \emph{Gromov-hyperbolic}, or \emph{hyperbolic}.
\end{definition}

\begin{example}
    If \(\diam(X) = \delta\), then \(X\) is \(\delta\)-hyperbolic.
\end{example}

\begin{example}
    If \(X\) is a tree, then \(X\) is \(0\)-hyperbolic.
\end{example}

\begin{example}
    [non-example]
    Euclidean space is not Gromov-hyperbolic.
\end{example}

\begin{example}
    \(\bb H^2\) is hyperbolic. To see this, \(\Delta\) is \(\delta\)-slim, where \(\delta\) is the radius of the largest semicircle which we can inscribe in \(\Delta\).

    Let \(A(r)\) be the area of a circle of radius \(r\) in \(\bb H^2\). But now
    \[\frac{1}{2}A(\delta) \le \Area(\Delta) < \pi\]
    Since \(A(\delta) \to \infty\) as \(\delta \to \infty\), we see that \(\bb H^2\) is \(\delta\)-hyperbolic for sufficiently large \(\delta\).
\end{example}

\subsection{The Mostow-Morse lemma}

The goal is to prove that Gromov-hyperbolicity is a quasi-isometry invariant.

\lec

\begin{definition}
    [quasigeodesic]
    A path \(\gamma : [a, b] \to X\) is a \emph{\((\lambda, \epsilon)\)-quasigeodesic} if \(\gamma\) is a \((\lambda, \epsilon)\)-quasi isometric embedding. That is,
    \[\frac{1}{\lambda}\abs{s - t} - \epsilon \le d(\gamma(s), \gamma(t)) \le \lambda\abs{s - t} + \epsilon\]
\end{definition}

\begin{definition}
    [Hausdoff distance] Let \(A, B \sse X\) be nonempty subsets of a metric space \(X\). Let
    \[N_C(A) = \bigcup_{a \in A}B_c(a) = \{x \in X \mid \exists a \in A, d(x, a) \le c\}\]
    The \emph{Hausdorff distance} is
    \[d_{\Haus}(A, B) = \inf\{c > 0 \mid A \sse N_c(B) \text{ and }B \sse N_c(A)\}\]
\end{definition}

\begin{definition}
    [length] Let \(\gamma : [a, b] \to X\) be a path. The \emph{length} of \(\gamma\) is
    \[\ell(\gamma) = \sup_{\mcD}\sum_{i=1}^n d(\gamma(t_{i-1}), \gamma(t_i))\]
    where \(\mcD\) ranges over all dissections
    \[a = t_0 < t_1 < \cdots < t_n = b\]
\end{definition}

\begin{lemma}
    \label{lem:quasi-geodesic-tame}
    For any \(\lambda \ge 1, \epsilon \ge 0\), there are \(\lambda' \ge 1, \epsilon' \ge 1\), such that for any geodesic metric space \(X\), and any \((\lambda, \epsilon)\)-quasigeodesic \(\alpha : [a, b] \to X\), there exists a continuous \((\lambda', \epsilon')\)-quasigeodesic \(\alpha' : [a, b] \to X\), such that
    \begin{enumerate}[(i)]
        \item \(\alpha'(a) = \alpha(a), \alpha'(b) = \alpha(b)\),
        \item \(d_\Haus(\im(\alpha), \im(\alpha')) \le \lambda + \epsilon\),
        \item \(\ell(\alpha'\vert_{[s, t]}) \le \lambda' d(\alpha'(s), \alpha'(t)) + \epsilon\), for all \(a \le s \le t \le b\).
    \end{enumerate}
\end{lemma}

\begin{proof}
    Let \(I = \{a, b\} \cup (a, b) \cap \Z\). Define \(\alpha'\) by setting \(\alpha'(t) = \alpha(t)\) for all \(t \in I\), and then interpolating using a (reparametrised) geodesic between points of \(I\).

    Continuity is clear, and so is (i). (ii) is easy. The fact that \(\alpha'\) is a quasi-geodesic and (iii) follow from easy, but tedious calculations.
\end{proof}

\begin{lemma}
    Let \(X\) be a \(\delta\)-hyperbolic metric space. Suppose \(\beta : [a, b] \to X\) is a geodesic, \(\alpha : [a, b] \to X\) is a continuous path, with \(\alpha(a) = \beta(a), \alpha(b) = \beta(b)\). Then
    \[d(\beta(t), \im(\alpha)) \le \delta\lfloor\log_2(\ell(\alpha))\rfloor + 1\]
\end{lemma}

\begin{proof}
    Let
    \[N = \lfloor \log_2(\ell(\alpha))\rfloor\]
    The proof proceeds by induction on \(N\). If \(N \le 0\) then \(\ell(\alpha) \le 1\) and we are done.

    Consider the geodesic triangle with vertices
    \[\alpha(a), \alpha(b), \alpha\!\!\left(\frac{a + b}{2}\right)\]
    Since \(X\) is \(\delta\)-hyperbolic, \(\beta(t)\) has distance at most \(\delta\) from one of the other edges of the triangle. Call the corresponding half of \(\alpha\) \(\alpha'\), and the geodesic \(\beta'\). Now
    \[\ell(\alpha') = \frac{\ell(\alpha)}{2} \implies \lfloor\log_2(\ell(\alpha'))\rfloor = N - 1\]
    and we have a point \(\beta'(t')\) such that \(d(\beta(t), \beta'(t')) \le \delta\). By inductive hypothesis,
    \begin{align*}
        d(\beta(t), \im(\alpha)) &\le d(\beta(t), \im(\alpha')) \\
        &\le d(\beta(t), \beta'(t')) + d(\beta'(t'), \im(\alpha')) \\
        &\le \delta + \delta(N - 1) + 1 \\
        &= \delta N + 1
    \end{align*}
    as required.
\end{proof}

We are now ready for the main result of this section:

\begin{theorem}
    [Mostow-Morse lemma] Let \(X\) be a (geodesic) \(\delta\)-hyperbolic space. Let \(\alpha : [a', b'] \to X\) be a \((\lambda, \epsilon)\)-quasigeodesic, and \(\beta : [a, b] \to X\) a geodesic, with
    \[\beta(a) = \alpha(a') \qqtext{and}\beta(b) = \alpha(b')\]
    Then there exists a constant \(C = C(\lambda, \epsilon, \delta)\), such that
    \[d_\Haus(\im(\alpha), \im(\beta)) \le C\]
\end{theorem}

\begin{proof}
    We may replace \(\alpha\) by the result of \cref{lem:quasi-geodesic-tame}. In particular, \(\alpha\) is continuous, and
    \[\ell\left(\alpha_{[s, t]}\right) \le \lambda \abs{s - t} + \epsilon\]
    for \(a \le s \le t \le b\). We need to bound
    \[C_1 = \inf\{C \mid \im(\beta)\sse N_C(\im(\alpha))\} \qqtext{and} C_2 \inf\{C \mid \im(\alpha) \sse N_C(\im(\beta))\}\]
    We'll first bound \(C_1\). For this, we'll need to bound
    \[d(\beta(t), \im(\alpha)) = \inf_{t' \in [a, b]}d(\beta(t), \alpha(t'))\]
    Let \(C = \sup\limits_{t \in [a, b]}d(\beta(t), \im(\alpha))\). Since \([a', b']\) is compact, it is realised at some \(\beta(t)\). Let
    \[r = \max\{a, t - 2C\} \qqtext{and} s = \min\{b, t + 2C\}\]
    Define the path \(\gamma\) by going from \(\beta(r)\) to the closest point \(\alpha(r')\) on \(\alpha\), following \(\alpha\) until the closest point \(\alpha(s')\) to \(\beta(s)\), and then going to \(\beta(s)\). Then
    \begin{align*}
        \ell(\gamma) &\le 2C + \ell(\alpha\vert_{[r', s']}) \\
        &\le 2C + \lambda\abs{r' - s'} + \epsilon \\
        &\le 6\lambda C + 2C + \epsilon
    \end{align*}
\end{proof}
