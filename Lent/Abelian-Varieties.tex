Recall that an \emph{elliptic curve} \(E\) over a field \(k\), which is a proper curve which is also a group. In particular, they are projective (in fact, we can write it as a nonsingular plane cubic), and that the group is commutative. If \(k\) is algebraically closed, then \(E(k)\) is divisible, and for all \(n \in \N\),
\[E[n] = \ker(n\cdot : E(k) \to E(k))\]
is finite. In particular, if \(n\) is invertible in \(k\), then
\[E[n] = \left(\Z/n\Z\right)^2\]
On the other hand, if \(\Char(k) = p > 0\), then either
\[E[p^r] = \Z/p^r\Z\]
for all \(r \ge 1\), or
\[E[p^r] = 0\]
for all \(r \ge 1\).

The \emph{Abel-Jacobi} theorem gives a homomorphism
\[E(k) \to \Cl^0(E) = \frac{\{\text{degree 0 divisors}\}}{\{\text{principal divisors}\}}\]
Given by \(P \mapsto (P) - (0)\). In fact, by Riemann-Roch, this is an isomorphism.

Abelian varieties are ``higher dimensional analogues of an elliptic curve''. That is, they are a proper variety over \(k\) which is a group. If \(X\) is an abelian variety, we will see:
\begin{itemize}
    \item \(X\) is projective and nonsingular,
    \item \(X\) is commutative,
    \item if \(k\) is algebraically closed, then \(X(k)\) is divisible, with
    \[X[n] \cong (\Z/n\Z)^{2g}\]
    where \(g = \dim(X)\), \(n\) invertible in \(k\). If \(\Char(k) = p > 0\), then
    \[X[p^r] = \left(\Z/p^r\Z\right)^t\]
    with \(0 \le t \le g\).
    \item and an analogue of the Abel-Jacobi theorem, there exists another abelian variety \(\widehat X\), with \(\dim(\widehat X) = g\), called the dual abelian variety, and an isomorphism
    \[\widehat X(k) \cong \Pic^0(X) \sse \Pic(X)\]
    where \(\Pic(X)\) is the group of isomorphism classes of line bundles on \(X\), which is in turn, isomorphic to the divisor class group. Moreover, we have a morphism \(X \to \widehat X\), which is surjective with finite kernel. Note that we don't need to have \(X \cong \widehat X\).
\end{itemize}

In contrast to the one-dimensional case, we need a lot of algebraic geometry, especially the cohomology of coherent sheaves to prove these. One reason is that unlike elliptic curves, we don't have nice equations for them.

\textbf{Conventions for this course:} Every ring will be commutative unital, and ring homomorphisms will be unital. If \(f : A \to B\) is a ring homomorphism, we say \(B\) is an \(A\)-algebra. We'll write \(ab\) for \(f(a)b\). An \(A\)-module is \emph{finite} if it is finitely generated. An \(A\)-algebra \(B\) is \emph{finite} if it is finite as an \(A\)-module, and it is of \emph{finite type} if it is finitely generated as an \(A\)-algebra.

A \emph{family} \((x_i)_{i \in I}\) of elements of a set \(S\) is just \(x_i \in S\), indexed by a set \(I\). This is the same as a function \(I \to S\). We'll write \(\#S\) for the size of a set \(S\), \(\subset\) and \(\sse\) will be used interchangably. Finally,
\[\N = \{0, 1, \dots\}\]

\section{K\"ahler differentials}

Let \(\varphi : A \to B\) be a ring homomorphism. We'll define a \(B\)-module \(\Omega_{B/A}\), which is the module of (K\"ahler) differentials, with an additive map \(\dd = \dd_{B/A} : B \to \Omega_{B/A}\), such that
\begin{align*}
    \dd(b_1b_2) &= b_1\dd b_2 + b_2 \dd b_1 \\
    \dd a = \dd(\varphi(a)) &= 0 \text{ for all }a \in A 
\end{align*} 
In particular, \(\dd\) is an \(A\)-linear map.

\begin{definition}
    We define \(\Omega_{B/A} = \mcP/\mcQ\), where
    \begin{align*}
        \mcP &= \text{free \(B\)-module on symbols }[b]\text{ for }b \in B \\
        \mcQ &= \text{submodule generated by }[a], [b_1 + b_2] - [b_1] - [b_2], [b_1b_2] - b_1[b_2] - b_2[b_1]
    \end{align*}
    and
    \[\dd b = [b] \mod \mcQ\]
\end{definition}

An \emph{\(A\)-derivation of \(B\) into a \(B\)-module \(M\)} is an additive map \(\DD : B \to M\), such that
\begin{align*}
    \DD(A) &= 0 \\
    \DD(b_1b_2) &= b_1D(b_2) + b_2 D(b_1)
\end{align*}
We will write \(\Der_A(B, M)\) for the set of \(A\)-derivations \(B \to M\). This is a \(B\)-module, with \((b'\DD)(b) = b'\DD(b)\). Moreover, \(\Der_A(B, \cdot)\) is a functor. That is, if we have a \(B\)-module homomorphism \(f : M \to M'\), then we have a map
\[\Der(A, M) \to \Der(A, M')\]
given by \(\DD \mapsto f \circ \DD\). In particular, \((\Omega_{B/A}, \dd_{B/A})\) is the \emph{universal} derivation.

\begin{proposition}
    Suppose \(M\) is a \(B\)-module, then there is an isomorphism of \(B\)-modules,
    \begin{align*}
        \Hom_B(\Omega_{B/A}, M) &\cong \Der_A(B, M) \\
        \psi &\mapsto \psi \circ \dd_{B/A}
    \end{align*}
\end{proposition}

\begin{proof}
    The fact that it is a \(B\)-module homomorphism is trivial. Let \(\DD \in \Der_A(B, M)\). Set \(\widetilde\psi : \mcP \to M\) to be \(B\)-linear, with \(\widetilde\psi([b]) = D(b)\). Since \(D\) is a derivation, \(\widetilde\psi(Q) = 0\), so we have a map \(\psi : \mcP/\mcQ = \Omega_{B/A} \to M\), with \(\psi \circ \dd = D\).

    On the other hand, if \(\psi \circ \dd = 0\), then \(\psi = 0\) since \(\Omega_{B/A}\) is generated by the image of \(\dd\).
\end{proof}

\lec

Another characterisation of \(\Omega_{B/A}\) is as follows. Consider the map \(\mu : B \otimes_A B \to B\), given by \(\mu(b_1 \otimes b_2) = b_1b_2\). In particular, \(\mu\) is a \(B\)-algebra homomorphism, for each of the \(B\)-algebra structues on \(B \otimes_A B\). Let \(J = \ker(\mu)\). Then \(J/J^2\) is a \(B \otimes_A B\)-module, killed by \(J\), so it is a \(B\)-module. In particular, all of the \(B\)-module structures on it agree.

Let
\begin{align*}
    \dd' : B &\to J/J^2 \\
    b &\mapsto (1 \otimes b - b \otimes 1) \mod J^2
\end{align*}
Then \(\dd'\) is an \(A\)-derivation. To see this,
\[\dd'(a) = 1 \otimes a - a \otimes 1 = 0\]
for all \(a \in A\). Next,
\begin{align*}
    b_1\dd'(b_2) &= (b_1 \otimes 1)(1 \otimes b_2 - b_2 \otimes 1) \mod J^2 \\
    &= b_1 \otimes b_2 -  b_1b_2 \otimes 1 \mod J^2
\end{align*}
and by symmetry,
\[b_2\dd'(b_1) = 1 \otimes b_1b_2 - b_1 \otimes b_2 \mod J^2\]
Adding these together gives the Leibniz rule. By the universal property, there exists a unique \(B\)-linear map \(\psi : \Omega_{B/A} \to J/J^2\), such that \(\psi \circ \dd = \dd'\).

\begin{proposition}
    \(\psi\) is an isomorphism.
\end{proposition}

So we could have defined \((\Omega_{B/A}, \dd)\) as \((J/J^2, \dd')\) instead.

\begin{proof}
    Consider the map
    \begin{align*}
        \varphi : B \otimes_A B &\to \Omega_{B/A} \\
        \varphi(b_1 \otimes b_2) &= b_1 \dd(b_2)
    \end{align*}
    Now
    \[J = \left\{\sum b_i \otimes b_i' \ \big\vert\ \sum b_ib_i' = 0\right\}\]
    We claim that \(J\) is generated (as a \(B\)-module) by elements of the form \(1 \otimes b - b \otimes 1\). To see this,
    \[\sum b_i \otimes b_i' = \sum (b_i \otimes 1)(1 \otimes b_i' - b_i' \otimes 1) + \sum b_ib_i' \otimes 1\]
    and the last term is zero. So it is a \(B\)-module under the \(b \otimes 1\) action. Now
    \begin{align*}
        \varphi((1 \otimes b - b \otimes 1)(1 \otimes b' - b' \otimes 1)) = 0
    \end{align*}
    and so \(\varphi\) vanishes on \(J^2\), and it factors through \((B \otimes_AB)/J^2\). It remains to check that \(\varphi \circ \psi = \id\) and \(\psi \circ \varphi\vert_{J/J^2} = \id\). We leave this as an exercise.
\end{proof}

\begin{example}
    If \(B = A[t_1, \dots, t_n]\) is the polynomial algebra, then
    \[\Omega_{B/A} = \oplus_{i=1}^n B\dd t_i\]
    is free. To see this,
    \[B \otimes_A B = A[\{t_i \otimes 1, 1 \otimes t_j\}] = A[\{t_i \otimes 1, z_i\}] = B[\{z_i\}]\]
    where \(z_i = 1 \otimes t_i - t_i \otimes 1\). Using this, the map \(\mu : B \otimes_A B \to B\) is just \(z_i \mapsto 0\) and the identity map on \(B\). So we have that
    \[J = \inner{z_1, \dots, z_n}\]
    and
    \[J^2 = \inner{z_iz_j}\]
    Thus, \(J/J^2\) is the free module
    \[\bigoplus_i B \cdot (z_i \mod J^2)\]
    But \(z_i \mod J^2\) is just \(\dd'(z_i) = \dd t_i\).
\end{example}

\begin{corollary}
    \label{cor:differential-poly-quot}
    If \(B = A[\{x_i\}]\), and \(C = B/\inner{\{f_j\}}\), then
    \[\Omega_{C/A} = \frac{\bigoplus_i C \dd x_i}{\sum C \dd f_j}\]
    In this case,
    \[\dd f_j = \sum_i \pdv{f_j}{x_i}\dd x_i\]
\end{corollary}

\subsection{Sheafification}

Let \(f : X \to Y\) be a morphism of schemes. We would like to define a quasicoherent \(\mcO_X\)-module \(\Omega_{X/Y}\), and a map
\[\dd : \mcO_X \to \Omega_{X/Y}\]
which is \(f^{-1}\mcO_Y\)-linear, and satisfies the Leibniz rule for sections. This is called the \emph{sheaf of relative differentials}, or the \emph{cotangent sheaf}. There are two constructions, let's see the `dirty' one first.

If we have open affines \(U = \Spec(B) \sse X\), \(V = \Spec(A) \sse Y\), with \(f(U) \sse V\), then we can define
\[\Omega_{X/Y}\vert_U = \widetilde{\Omega_{B/A}}\]
where \(\widetilde{\Omega_{B/A}}\) is the quasicoherent \(\mcO_U\)-module attached to the \(B\)-module \(\Omega_{B/A}\). The map \(\dd\) is induced by

\begin{proposition}
    If \(f : X \to Y\) is of finite type, and \(X\) and \(Y\) are Noetherian, then \(\Omega_{X/Y}\) is coherent\footnote{i.e. affine locally it is the sheaf associated to a finite module.}.
\end{proposition}

    Locally, we can cover \(X\) with \(\Spec(B)\), such that \(f(\Spec(B)) \sse \Spec(A)\), and this makes \(B\) a finite type \(A\)-algebra. That is,
    \[B = \frac{A[t_1, \dots, t_m]}{I}\]
    where \(I = \inner{f_1, \dots, f_n}\). The second exact sequence is

        {I/I^2} & {\Omega_{A[\mathbf t]/A}\otimes_{A[\mathbf t]}B} & {\Omega_{B/A}} & 0
        \arrow[from=1-1, to=1-2]

    \[\Omega_{A[\mathbf t]/A}\otimes_{A[\mathbf t]}B = \bigoplus_i B \dd t_i\]
    and so \(\Omega_{B/A}\) is a finite \(B\)-module, and so \(\Omega_{X/Y}\) is coherent.

For field extensions, \(\Omega\) tells us whether the extension is separable.

\begin{example}
    Let \(L/K\) be a finite field extension. Then \(L/K\) is separable if and only if \(\Omega_{L/K} = 0\). To see this, factor the extension as \(K \sse K_1 \sse L\), with \(K_1/K\) separable, and \(L/K_1\) purely inseparable. That is, \(K_1\) is the set of all elements of \(L\) which is separable over \(K\).

    By the primitive element theorem, \(K_1 = K(\alpha) = K[t]/\inner{g}\), where \(g \in K[t]\) is irreducible, \(g(\alpha) = 0\) and \(g'(\alpha) \ne 0\). So
    \[\Omega_{K_1/K} = \frac{K_1\dd\alpha}{K_1g'(\alpha)\dd\alpha}\]
    by \cref{cor:differential-poly-quot}. But this is zero as \(g'(\alpha) \ne 0\). In this case, transitivity gives us \(\Omega_{L/K} = \Omega_{L/K_1}\). If \(L = K_1\), i.e. \(L/K\) is separable, then \(\Omega_{L/K_1} = 0\).

    Conversely, if \(L/K\) is inseparable, then there exists \(K_2\) with \(K_1 \sse K_2 \sse L\), such that \(L = K_2(\beta) = K_2[t]/\inner{t^p - b}\), with \(p = \Char(K) > 0\), \(b \in K_2\) is not a \(p\)-th power. In this case.
    \[\Omega_{L/K_2} = L\dd\beta\]
    since in this case, \(\dv{t}(t^p - b) = 0\). Thus, by transitivity again, \(\Omega_{L/K}\ne 0\).
\end{example}

\subsection{Tangent and cotangent spaces}

Let \(X\) be a \(k\)-scheme, locally of finite type. That is, \(X\) has an open cover by affines \(\Spec(A)\), where \(A\) is a finite type \(k\)-algebra. Let \(\abs{X}\) denote the set of closed points of \(X\). If \(x \in \abs{X}\), then the residue field at \(k\),
\[\kappa(x) = \mcO_{X, x}/\mfm_x\]
is a finite extension of \(k\). Define
\[\Omega_{X/k}(x) = \Omega_{X/k, x} \otimes_{\mcO_{X, x}} \kappa(x)\]
This is a finite dimensional \(\kappa(x)\) vector space. This follows from the fact that \(\Omega_{X/k}\) is coherent. We call this the \emph{cotangent space of \(X\) at \(x\)}.

The corresponding \emph{tangent space} is
\[\T_{X, x} = \Hom_{\kappa(x)}(\Omega_{X/k}(x), \kappa(x))\]

\begin{proposition}
    If \(\kappa(x) = k\), then there exists a canonical isomorphism
    \[\Omega_{X/k}(x) \cong \mfm_x/\mfm_x^2\]
    of \(k\)-vector spaces.
\end{proposition}

\begin{proof}
    In this case,
    \[\Omega_{X/k}(x) = \Omega_{\mcO_{X, x}/k}\otimes_{\mcO_{X, x}} k\]
    The second exact sequence gives us that

\[\begin{tikzcd}

    \[\Hom_{\mcO_{X, x}/k}(\Omega_{\mcO_{X, x}/k}, k) \to \Hom_k(\mfm_x/\mfm_x^2, k)\]
    is surjective. The left hand side can be identified with
    \[\Der_k(\Omega_{X, x}, k)\]
    and so the map is given by
    \[\DD \mapsto \left(f + \mfm_x^2 \mapsto \DD(f) \mod \mfm\right)\]
    Since \(\DD(\mfm_x^2) = 0\) by Leibniz. As \(\mcO_{X, x}/\mfm_x = k \inj \mcO_{X, x}\), we must have that
    \[\mcO_{X, x}/\mfm^2 = k \oplus \mfm_x/\mfm_x^2\]
    as \(k\)-vector spaces. Let \(\pi : \mcO_{X, x}/\mfm_x^2 \to \mfm_x/\mfm_x^2\) be the projection. For \(\varphi : \mfm_x/\mfm_x^2 \to k\), the map \(\DD = \varphi \circ \pi\) is a derivation which maps to \(\varphi\).

\begin{remark}
    THe statement holds more generally, if \(\kappa(x)\) is separable over \(k\).
\end{remark}

This leads to a ``geometric'' interpretation of the tangent space.

\begin{proposition}
    Let \(x \in \abs{X}\), \(X\) locally of finite type over \(k\), and suppose \(\kappa(x) = k\). Then
    \[\T_{X, x} \cong \left\{\text{morphisms of }k\text{-schemes} \Spec\left(\frac{k[\epsilon]}{\inner{\epsilon^2}}\right) \to X \text{ whose image is }X\right\}\]
\end{proposition}

The ring \(k[\epsilon]/\inner{\epsilon^2}\) is called the ring of \(\emph{dual numbers}\), and \(\Spec(k[\epsilon]/\inner{\epsilon^2}) = \{\inner{\epsilon}\}\). The map \(\Spec(k) \to \Spec(k[\epsilon]/\inner{\epsilon^2})\) is given by sending \(\epsilon\) to \(0\). This is a closed immersion.

Morally, \(\Spec(k[\epsilon]/\inner{\epsilon^2})\) is ``a point with a direction''.

\begin{proof}
    Giving such a morphism is equivalent to giving a local homomorphism
    \[\varphi : \mcO_{X, x} \to \frac{k[\epsilon]}{\inner{\epsilon^2}}\]
    of \(k\)-algebras. But \(\mcO_{X, x} = k \oplus \mfm_x\), since \(k\) is the residue field. So \(\varphi\) is determined by its restriction to \(\mfm\), which is a \(k\)-linear map \(\mfm_x \to k\epsilon \sse k[\epsilon]/\inner{\epsilon^2}\) (as it is a \emph{local map}).

    Since \(\epsilon^2 = 0\), \(\varphi\) is zero on \(\mfm_x^2\). So it is a \(k\)-linear map
    \[\mfm_x/\mfm_x^2 \to k\epsilon \cong k\]
    So the set of such morphisms is isomorphic to
    \[\Hom_k(\mfm_x/\mfm_x^2, k) \cong \Hom_k(\Omega_{X/k}(x), k) = \T_{X, x}\]
\end{proof}

As above, this is also true when \(\kappa(x)/k\) is separable.

\underline{Aside:} In the proofs of the above, we used the fact that if \(\kappa(x) = k\), then
\[\mcO_{X, x} = k \oplus \mfm_x\]
If \(\kappa(x) \ne k\), in general, \(\mcO_{X, x}\) will not be a \(\kappa(x)\)-algebra. But it is the case (at least) when \(\kappa(x)/k\) is separable. But
\[\frac{\mcO_{X, x}}{\mfm_x^2} \cong \kappa(x) \oplus \frac{\mfm_x}{\mfm_x^2}\]
That is, there is a field inside \(\mcO_{X, x}/\mfm_x^2\), which maps isomorphically onto \(\kappa(x)\). The proof is just Hensel's lemma, write \(\kappa(x) = k(\alpha)\), with \(g(\alpha) = 0\). Lift \(g(\alpha)\) to a solution of \(g(t) \equiv 0 \mod \mfm^2\).

As an example, let \(X = \aff 1 \Q = \Spec(\Q[t])\), and let \(x = \inner{t^2 + 1} \in X\). Then \(\kappa(x) = \Q(i)\). But \(\Q(i)\) can't be a subfield of the local ring
\[\mcO_{X, x} \sse \Q(t)\]
But the completion
\[\invlim_n \frac{\mcO_{X, x}}{\mfm_x^n}\]
does contain a copy of \(\kappa(x)\).

\subsection{Nonsingular varieties}

Let \(X\) be an integral scheme of finite type over a field \(k\). Let \(d = \dim(X)\).

We say that \(X\) is \emph{smooth} over \(k\) if \(\Omega_{X/k}\) is locally free of rank \(d\). If \(k\) is algebraically closed, then this is equivalent to the other conditions:

\begin{theorem}
    Suppose \(X\) is an integral scheme of dimension \(d\), and of finite type over an algebraically closed field \(k\). Then the following are equivalent.
    \begin{enumerate}[(i)]
        \item \(X\) is smooth over \(k\),
        \item for all \(x \in \abs{X}\), \(\dim_k(\T_{X, x}) = d\),
        \item for all \(x \in \abs{X}\),  the local ring \(\mcO_{X, x}\) is \emph{regular}\footnote{A Noetherian local domain \(R\) of dimension \(d\) is regular if it's maximal ideal \(\mfm\) can be generated by \(d\) elements.} (of dimension \(d\)).
    \end{enumerate}
\end{theorem}

\begin{proof}
    We know \(\dim_k(\T_{X, x}) = \dim_k(\mfm_x/\mfm_x^2)\).

    To show (ii) and (iii) are equivalent, note that
    \[\mfm_x/\mfm_x^2 = \mfm_x \otimes_{\mcO_{X, x}}k\]
    and \(\mfm_x\) is a finite \(\mcO_X\)-module. Nakayama's lemma implies that if \(t_1, \dots, t_n \in \mfm_x\), then \(\mfm_x = \inner{t_1, \dots, t_n}\) if and only if \(t_i + \mfm_x^2\) generate \(\mfm_x/\mfm_x^2\) as a \(k\)-vector space.

    To show (i) implies (ii),
    \[\T_{X, x} = \Hom_k(\Omega_{X/k}(x), k)\]
    this has dimension \(d\) as \(\Omega_{X/k}\) is locally free of rank \(d\). For (ii) implies (i), let \(K\) be the function field\footnote{i.e. the local ring at the unique generic point.} of \(X\). Now as \(k\) is algebraically closed, \(K\) is a finite separable extension of \(K_0 = k(t_1, \dots, t_d)\), for \(t_i \in K\) algebraically independent over \(k\). Hence
    \[\Omega_{K/k} = \Omega_{K_0/K} \otimes_{K_0} K\]
    and so
    \[\Omega_{K_0/k} = \bigoplus_i K_0 \dd t_i\]
    Thus, \(\dim_K(\Omega_{K/k}) = d\). But
    \[\Omega_{K/k} = \Omega_{X/k, \eta}\]
    
    \begin{lemma}
        Let \(X\) be as above.
        \begin{enumerate}[(i)]
            \item \(\mcF\) a coherent sheaf \(\mcO_X\)-module, such that for all closed points \(x \in \abs{X}\), \(\dim_k(\mcF_x \otimes_{\mcO_{X, x}} k)\) is the same as \(\dim_k(\mcF_\eta) = n\), then \(\mcF\) is locally free.
            \item In general, there exists a non-empty open subscheme \(U \sse X\), such that for all \(x \in \abs{X}\), \(\mcF_x\) is free if and only if \(x \in U\).
        \end{enumerate}
    \end{lemma}

    \begin{remark}
        There are two notions of locally free for any \(A\)-module \(M\). The first is that \(M_\mfp\) is free for all \(\mfp \in \Spec(A)\). The second is that \(\widetilde M\) is a locally free sheaf on \(\Spec(A)\).
        
        These are not equivalent in general. For example, \(A = \Z\) and
        \[M = \left\{\frac{m}{n} \ \bigg\vert\ n\text{ squarefree}\right\} \sse \Q\]
        \(M_\mfp\) is free, but \(\widetilde M\) is not locally free.

        In the course, we will always use the second one. If \(A\) is Noetherian, and \(M\) is finite, then the two are equivalent.
    \end{remark}
    \lec

    \begin{proof}
        [Proof of lemma]
        For both of these statements, we can assume that \(X = \Spec(A)\) is affine, and \(\mcF = \widetilde M\), for a finite \(A\)-module \(M\). \(K = \Frac(A)\), so \(n = \dim_K(M \otimes_A K)\).

        Let \(\mfm \in \maxSpec(A)\) be a maximal ideal. By assumption,
        \[n = \dim_K(M \otimes (A /\mfm))\]
        Choose \(t_1, \dots, t_n \in M\), whose images in \(M/\mfm M\) form a basis. Now consider the natural map\footnote{i.e. \((a_1, \dots, a_n) \mapsto a_1t_1 + \cdots + a_nt_n\).} \(A^n \to M\) from this basis. By Nakayama, the localisation
        \[A^n_\mfm \to M_\mfm\]
        is surjective. So the map \(K^n \to M \otimes_A K\) is surjective, so it is an isomorphism. Hence the above map is an isomorphism.

        We need to show that there exists a nonempty open \(U \sse \Spec(A)\), such that the map
        \[\mcO_U^n \to \widetilde M\vert_U\]
        is an isomorphism. We know that the map \(A^n \to M\) is injective, and has finite torsion cokernel \(N\) say, since it is an isomorphism after tensoring with \(K\). Then the map
        \[\mcO_U^n \to \widetilde M\vert_U\]
        is an isomorphism for \(U = X \setminus \van(\Ann(N))\). Now note that \(\Ann(N)\) is non-zero, so \(U\) is non-empty. Moreover, \(\Ann(M) \not\subseteq \mfm\), so \(\mfm \in U\).

        For (ii), choose \(t_i \in M\) such that the map \(K^n \to M\otimes_A K\) is an isomorphism. The corresponding map \(A^n \to M\) has finite torsion cokernel as above, and so at a maximal ideal \(\mfm\), we have an isomorphism \(A_\mfm^n \to M_\mfm\) if and only if \(\mfm \notin \van(\Ann(\coker(\cdot)))\).
    \end{proof}
\end{proof}

\begin{remark}
    The theorem holds more generally, for \(k\) perfect. But it fails for general \(k\). Let \(X = \Spec(K)\), where \(K = k(t^{1/p})\), \(k = \bb F_p(t)\). Here,
    \[\Omega_{K/k} = K(t)\dd(t^{1/p})\]
    is non-zero, but \(K\) is clearly regular (of dimension \(0\)).

    Thus, over non-perfect fields, regular and smoothness are not equivalent.
\end{remark}

\begin{theorem}
    Let \(k\) be algebraically closed, \(X/k\) an integral scheme of finite type over \(k\), then there exists a maximal non-empty open \(U \sse X\) which is smooth over \(k\).    
\end{theorem}

\begin{proof}
    As in the proof of (ii) implies (i) in the previous theorem, we know that
    \[\Omega_{X/k, \eta} \cong \kappa(X)^d\]
    The second part of the lemma says that there exists a non-empty open \(U\), such that for all \(x \in \abs{X}\), \(x \in U\) if and only if \(\Omega_{X/k, x}\) is free of rank \(d\). But by the theorem, this is the same as
    \[\dim_k(T_{X, x}) = d\]
\end{proof}

\subsection{Digression - some general (nice) properties of schemes}

Let \(X\) be a scheme. Recall:
\begin{itemize}
    \item \(X\) is \emph{quasicompact} if \(X\) is a finite union of open affines.
    \begin{example}
        [non-example]
        Let \(X = \A^\infty_k = \Spec(k[x_1, x_2, \dots])\), and \(U = X \setminus \{0\}\). This is not quasicompact.
    \end{example}
    \item \(X\) is \emph{separated} if the diagonal map is closed. In this case, the intersection of open affines is an open affine.
    \begin{example}
        [non-example] The bug-eyed plane is not separated.
    \end{example}
    \item (for completeness) \(X\) is \emph{quasi-separated} if the intersection of any two open affines is quasicompact.
    \begin{example}
        [non-example] Let \(X\) be the union of two copies of \(\A^\infty_k\), glued on the complement of the origin.
    \end{example}
\end{itemize}

Sometimes, people will say ``\(X\) is \emph{qcqs}'', to say \(X\) is quasicoherent and quasiseparated.

If \(f : X \to Y\) is a morphism,
\begin{itemize}
    \item it is \emph{quasicompact}, if for all open affines \(V \sse Y\), \(f^{-1}(V)\) is quasicompact,
    \item it is \emph{locally of finite type}, if for all \(x \in X\), there exists an open affine neighbourhoods \(x \in U = \Spec(B)\), and \(f(U) \sse V = \Spec(A)\), where \(B\) is a finite type \(A\)-algebra.
    \item it is of \emph{finite type} if it is quasicompact and locally of finite type.
    \item (for completeness) it is \emph{locally of finite presentation} if locally it is \(\Spec(B) \to \Spec(A)\), where \(B\) is a finitely presented \(A\)-algebra. So
    \[B = \frac{A[x_1, \dots, x_n]}{\inner{f_1, \dots, f_m}}\]
    When \(A\) is Noetherian, this is the same as locally of finite type. That is, when \(Y\) is locally Noetherian. In this case, \(f\) is \emph{of finite presentation} if moreover it is quasicompact and quasiseparated.
\end{itemize}

Returning to (algebraic) geometry: Let \(f : X \to Y\) be a morphism of schemes. We say that \(f\) is \emph{flat} if one of the following (equivalent) conditions are satisfied:
\begin{itemize}
    \item locally, \(f\) is of the form \(\Spec(B) \to \Spec(A)\), where \(B\) is a flat \(A\)-algebra,
    \item for all \(x \in X\), \(\mcO_{X, x}\) is flat over \(\mcO_{Y, f(x)}\).
\end{itemize}
More generally, a queasicoherent \(\mcO_X\)-module \(\mcF\) is \emph{flat over \(Y\)} if for all \(x \in X\), \(\mcF_x\) is a flat \(\mcO_{Y, f(x)}\)-module.

\begin{example}
    Open immersions are flat, since locally, they are isomorphisms. Closed immersions are in general, not flat.
\end{example}

Let \(X, Y\) be \(k\)-schemes. Then
\[X \times_{\Spec(k)} Y \to Y\]
is flat. Morally, flatness is  saying that ``the fibres vary continuously''.

See more in section in Hartshorne on flat morphisms, especially Example III.9.8.4, of a particular flat family of curves.

\underline{Fact:} Let \(f : X \to Y\) be a flat morphism of integral \(k\)-schemes of finite type. Then for all \(y \in Y\), and every irreducible component \(Z \sse f^{-1}(y)\), \(\dim(Z)\) is independent of choice of \(y, Z\), and is equal to \(\dim(X) - \dim(Y)\).

\begin{example}
    Let \(Y = \P^2_k\), and let \(X\) be the blowup of \(Y\) at a point \(y \in Y(k)\)\footnote{\(Y(k) = \Hom_{\Spec(k)}(\Spec(k), Y)\) is the set of \(k\)-points of \(Y\).}. Then for all \(y' \ne y\), \(f^{-1}(y')\) is a point, as we have an isomorphism \(X \setminus f^{-1}(y) \cong Y \setminus \{y\}\). But \(f^{-1}(y) = \P^1_k\). So \(f\) is not flat.
\end{example}

As an example of blowup for \(\A^2\), consider
\[\{(x_0, x_1), (y_0:y_1) \mid x_0y_1 = x_1y_0\} \sse \A^2 \times \P^1\]
and the projection onto the \(\A^2\)-factor. Away from the origin, the fibre is a line. At the origin, the fibre is a \(\P^1\).

\lec

One way to think about this is that fibre dimension is constant across a flat family.

\begin{example}
    Let \(Y = \Spec(k[t])\), and take \(X = \Spec(k[x,y,t]/\inner{xy-t})\). We have a ring map \(k[t] \to k[x,y,t]/\inner{xy-t}\), so we have a scheme map \(X \to Y\).

    When \(a\) is non-zero, the fibre is the (smooth irreducible) conic \(xy = a\). When \(a = 0\), then we have the singular curve \(xy = 0\), and the fibre is reducible.

    If instead we considered \(X = \Spec(k[x,y,t]/\inner{x^2 - ty})\). When \(t = 0\), we have \(x^2 = 0\), which is a non-reduced scheme.
\end{example}

We have the very useful result:

\begin{theorem}
    [(a special case of) miracle flatness] Let \(X, Y\) be integral \(k\)-schemes of finite type and smooth over \(k\). Let \(f : X \to Y\) be a morphism. Suppose that for all \(y \in Y\), and for all irreducible components \(Z \sse f^{-1}(y)\), \(\dim(Z) = \dim(X) - \dim(Y)\). Then \(f\) is flat.
\end{theorem}

This is actually true under much weaker hypotheses on \(X\). See Eisenbud Commutative Algebra for a proof.

\underline{Fact:} Let \(f : X \to Y\) be flat, and locally of finite presentation (for example, if \(X, Y\) are Noetherian, then \(f\) just has to be flat of finite type). Then \(f\) is an open map.

Note that a finiteness condition is necessary, for example, if \(X = \Spec(\Q) \inj \Spec(Z) = Y\), then this is flat but not open.

\subsection{Homological algebra}

Recall a \emph{(cochain) complex of abelian groups (or \(R\)-modules, or sheaves)} is a sequence of maps \((A^\bullet, \dd)\)

\[\HH^p(A^\bullet) = \frac{\ker(\dd : A^p \to A^{p+1})}{\im(\dd : A^{p-1} \to A^p)}\]
We write
\[\HH^*(A^\bullet) = \bigoplus_p \HH^p(A^\bullet)\]
for the graded \(R\)-module. A \emph{morphism of complexes} \(f : (A, \dd) \to (B, \dd)\) is a family of maps \(f^p : A^p \to B^p\), such that
\[\dd f = f \dd\]
This induces homomorphisms
\[\HH^p(f) : \HH^p(A^\bullet) \to \HH^p(B^\bullet)\]

Suppose \(f, g : A \to B\) are morphisms of chain complexes. They are \emph{homotopic} if there exists maps \(h^p : A^p \to B^{p-1}\), such that
\[\dd h + h \dd = f - g\]
If \(f\) and \(g\) are homotopic, then they induce the same map on cohomology. In particular, if \(A = B\), and \(h^p : A^p \to A^{p-1}\) are such that
\[\dd h + h \dd  = \id\]
Then the identity and zero maps on cohomology are equal, so the cohomology is zero. If such an \(h\) exists, we say that \(A\) is null-homotopic.

\begin{example}
    Let \(A\) be a cochain complex of abelian groups, \(n \ge 0\). Let \(\Z[-n]\) be the complex which is \(\Z\) in degree \(n\), and zero otherwise. Then the set of morphisms \(\Z[-n] \to A\) is the same as the set of maps \(f : \Z \to A^n\), with \(\dd f = 0\). But any such map is of the form \(f(k) = kx\) for some \(x \in \ker(\dd : A^p \to A^{p+1})\). Moreover, the homotopy classes of such maps is the above quotiented by \(\im(\dd : A^{p-1} \to A^p)\), i.e. \(\HH^n(A)\). So we obtain the identification
    \[\HH^n(A) = \{\text{homotopy classes of morphisms }\Z[-n]  \to A\}\]
\end{example}

Suppose \((A^\bullet, \dd_A), (B^\bullet, \dd_B)\) are complexes of \(R\)-modules. We define the \emph{tensor product} \(A \otimes_R B\) as follows: In degree \(n\), we have
\[(A \oplus_R B)^n = \bigoplus_{p + q = n} A^p \otimes_R B^q\]
For \(x \in A^p, y \in B^q\), the differential is
\[\dd(x \otimes y) = \dd_A x \otimes y + (-1)^px \otimes \dd_B y\]
Note that the sign is required for \(\dd^2 = 0\).

\begin{theorem}
    [na\"ive K\"unneth] Suppose \(R = k\) is a field, then for all \(n \ge 0\),
    \[\HH^n(A \otimes_k B) = \bigoplus_{p + q = n}\HH^p(A) \otimes_k \HH^q(B)\]
\end{theorem}

\begin{proof}
    Consider \(\HH^\bullet(A)\) to be a complex, with differential being zero. The cohomology groups are \(\HH^\bullet(A)\). Now as the \(A^p\) are \(k\)-vector spaces, we can write
    \[A^\bullet \cong \HH^\bullet(A) \oplus C^\bullet\]
    where \(\HH^*(C) = 0\). Thus, \(C\) is null-homotopic, via a chain homotopy \(h^\bullet\). Then 
    \[A \otimes_k B = H^\bullet(A) \otimes_k B \oplus C^\bullet \otimes_k B^\bullet\]
    It's easy to see that \(h \otimes \id_B\) shows \(C^\bullet \otimes_k B^\bullet\) is null-homotopic. Do the same with \(B\), and we see that
    \[\HH^n(A \otimes_k B) = \HH^n(\HH^\bullet(A) \otimes_k \HH^\bullet(B)) = \bigoplus_{p + q = n}\HH^p(A) \otimes_k \HH^q(B)\]
\end{proof}

where \(\mcF_K\) is the pullback. We will prove a more general result later.

    \[\begin{tikzcd}
        0 & {\mcF(V)} & {\check\mcC^0(\mcU, \mcF)(V)} & \cdots
        \arrow[from=1-1, to=1-2]
        \arrow[from=1-2, to=1-3]
        \arrow[from=1-3, to=1-4]
    \end{tikzcd}\]
    But
    \[\check\mcC^i(\mcU, \mcF)(V) = \check \mcC^i((U_i \cap V), \mcF\vert_V)\]
    But we know that
    \[\mcC^i((U_i \cap V), \mcF\vert_V) = \begin{cases}
        \mcF(V) & i = 0 \\
        0 & i > 0
    \end{cases}\]
    and so the result follows.
\end{proof}

\begin{definition}
    [resolution]
    Suppose

\[\begin{tikzcd}
	0 & \mcF & {\mcG^0} & {\mcG^1} & \cdots
	\arrow[from=1-1, to=1-2]
	\arrow[from=1-2, to=1-3]
	\arrow[from=1-3, to=1-4]
	\arrow[from=1-4, to=1-5]
\end{tikzcd}\]
    is an exact sequence, we say that the complex \((\mcG^\bullet)\) is a \emph{resolution} of \(\mcF\).
\end{definition}

In particular, (i) in the proposition is called the \emph{\v Cech resolution} of \(\mcF\).

\begin{definition}
    [acyclic]
    Let \(X\) be a topological space. A sheaf \(\mcG\) on \(X\) is \emph{acyclic} if for all \(i > 0\), \(\HH^i(X, \mcG) = 0\).
\end{definition}

\begin{theorem}
    [resolution principle]

    Let \(X\) be a topological space, \(\mcF\) be an abelian sheaf on \(X\), and \(\mcF \to \mcG^\bullet\) a resolution of \(\mcF\) by acyclic sheaves \(\mcG^p\). Then
    \[\HH^n(X, \mcF) = \HH^n(\Gamma(X, \mcG^\bullet))\]
\end{theorem}

\begin{example}
    Let \(\mcF\) be a quasicoherent \(\mcO_X\)-module, on a scheme \(X\), and \(\mcU\) is an open affine cover of \(X\). By the proposition,
    % https://q.uiver.app/#q=WzAsNSxbMCwwLCIwIl0sWzEsMCwiXFxtY0YiXSxbMiwwLCJcXGNoZWNrXFxtY0NeMChcXG1jVSwgXFxtY0YpIl0sWzMsMCwiXFxjaGVja1xcbWNDXjEoXFxtY1UsIFxcbWNGKSJdLFs0LDAsIlxcY2RvdHMiXSxbMCwxXSxbMSwyXSxbMiwzXSxbMyw0XV0=
\[\begin{tikzcd}
	0 & \mcF & {\check\mcC^0(\mcU, \mcF)} & {\check\mcC^1(\mcU, \mcF)} & \cdots
	\arrow[from=1-1, to=1-2]
	\arrow[from=1-2, to=1-3]
	\arrow[from=1-3, to=1-4]
	\arrow[from=1-4, to=1-5]
\end{tikzcd}\]
    is an acyclic resolution of \(\mcF\). Thus, the resolution principle gives us that
    \[\HH^i(X, \mcF) = \HH^n(\Gamma(X, \check\mcC^\bullet(\mcU, \mcF))) = \check\HH^i(\mcU, \mcF)\]
    So sheaf cohomology agrees with \v Cech cohomology.
\end{example}

	\arrow[from=1-4, to=1-5]
\end{tikzcd}\]
    where \(\dd^i\) is the map \(\mcG^i \to \mcG^{i+1}\), and
    % https://q.uiver.app/#q=WzAsNSxbMCwwLCIwIl0sWzEsMCwiXFxpbShcXGRkXntpLTF9KSJdLFsyLDAsIlxcbWNHXmkiXSxbMywwLCJcXGltKFxcZGReaSkiXSxbNCwwLCIwIl0sWzAsMV0sWzEsMl0sWzIsM10sWzMsNF1d
    \[\begin{tikzcd}

    % https://q.uiver.app/#q=WzAsNixbMSwwLCJcXEhIXjAoWCwgXFxtY0YpIl0sWzIsMCwiXFxISF4wKFgsIFxcbWNHXjApIl0sWzMsMCwiXFxISF4wKFgsIFxcaW0oXFxkZF4wKSkiXSxbMSwxLCJcXEhIXjEoWCwgXFxtY0YpIl0sWzIsMSwiMCJdLFswLDAsIjAiXSxbNSwwXSxbMCwxXSxbMSwyXSxbMiwzXSxbMyw0XV0=

        \arrow[from=1-1, to=1-2]
        \arrow[from=1-2, to=1-3]

We can also use other acyclic resolution.

\begin{definition}
    [flasque]
    Let \(X\) be a topological space. A sheaf \(\mcF\) on \(X\) is \emph{flasque}\footnote{in French} (or \emph{flabby}\footnote{when translated}, or \emph{flask}\footnote{when translated in America}) if for all opens \(V \sse U\), the restriction map \(\mcF(U) \to \mcF(V)\) is surjective.
\end{definition}

\underline{Fact:} Flasque sheaves are acyclic.

For any sheaf \(\mcF\), there exists an injection
\[\mcF \to \mathrm G\mcF = \prod_{x \in X}(i_x)_*\mcF_x\]
where \(i_x : \{x\} \inj X\) is the inclusion map. Then \(\mathrm G\mcF\) is flasque, and we have a resolution
% https://q.uiver.app/#q=WzAsNSxbMCwwLCIwIl0sWzEsMCwiXFxtY0YiXSxbMiwwLCJcXG1hdGhybSBHXFxtY0YiXSxbMywwLCJcXG1hdGhybSBHKFxcbWF0aHJtIEcgXFxtY0YpIl0sWzQsMCwiXFxjZG90cyJdLFswLDFdLFsxLDJdLFsyLDNdLFszLDRdXQ==
\[\begin{tikzcd}

\begin{theorem}
    Let \(\iota : Y \inj X\) be the inclusion of a closed subspace of a topological space \(X\). Let \(\mcF\) be a sheaf on \(Y\). Then
    \[\HH^*(Y, \mcF) = \HH^*(X, \iota_*\mcF)\]
    By abuse of notation, often we will write \(\HH^*(X, \mcF)\).
\end{theorem}

\begin{proof}
    Choose a flasque resolution \(\mcF \to \mcG^\bullet\) on \(Y\). By the resolution principle,
    \[\HH^*(Y, \mcF) = \HH^*(\Gamma(Y, G^\bullet))\]
    By the detinition, since \(\mcG^p\) is flasque, so is \(\iota_*\mcG^p\), and \(\iota_*\mcF \to \iota_*\mcG^\bullet\) is also a resolution. For this, note that we can check exactness on stalks, to see that \(\iota_*\) is exact.

    So
    \[\HH^*(X, \iota_*\mcF) =  \HH^*(\Gamma(X, \iota_*G^\bullet)) = \HH^*(\Gamma(Y, G^\bullet))\]
\end{proof}

\begin{theorem}
    [K\"unneth] 
    \label{thm:kunneth}
    Let \(X, Y\) be Noetherian separated schemes over a field \(k\), \(\mcF, \mcG\) quasicoherent sheaves on \(X\) and \(Y\) respectively. Then
    \[\HH^n(X \times_k Y, \pr_1^*\mcF \underset{\mcO_{X \times_k Y}}{\otimes} \pr_2^*\mcG) = \bigoplus_{p + q = n}\HH^p(X, \mcF) \otimes_k \HH^q(Y, \mcG)\]
    In particular,
    \[\HH^n(X \times_k Y, \mcO_{X \times_k Y}) = \bigoplus_{p + q = n}\HH^p(X, \mcO_X)\otimes_k \HH^q(Y, \mcO_Y)\]
\end{theorem}

\begin{notation}
    We will denote
    \[\mcF\boxtimes \mcG = \mcF \underset{X, Y}{\boxtimes} \mcG = \pr_1^*\mcF \underset{\mcO_{X \times_k Y}}\otimes \pr_2^*\mcG\]
\end{notation}

\begin{lemma}
    \begin{enumerate}[(i)]
        \item Let \(A, B\) be \(k\)-algebras, \(M\) an \(A\)-module, \(N\) a \(B\)-module, then on \(\Spec(A) \times_k \Spec(B) = \Spec(A \otimes_k B)\),
        \[\widetilde M \boxtimes \widetilde N = \widetilde{M \otimes_k N}\]
        \item if \(\mcF \to \mcK^\bullet\), \(\mcG \to \mcL^\bullet\) are resolutions of quasicoherent sheaves on \(k\)-schemes \(X, Y\), then
        \[\mcF \boxtimes \mcG \to \mcK^\bullet \boxtimes \mcL^\bullet\]
        is a resolution of quasicoherent sheaves on \(X \times Y\), where
        \[(\mcK^\bullet \boxtimes \mcL^\bullet)^n = \bigoplus_{p + q = n}\mcK^p \boxtimes \mcL^q\]
    \end{enumerate}
\end{lemma}

\begin{proof}
    For (i), note
    \[\pr_1^*(\widetilde M) = \widetilde{M \otimes_A (A \otimes_k B)}\]
    and so
    \begin{align*}
        \widetilde M \boxtimes \widetilde N &= \widetilde{\left(M \otimes_A (A \otimes_k B)\right)} \otimes \widetilde{\left(N \otimes_B (A \otimes_K B)\right)} \\
        &= \widetilde{M \otimes_k N}
    \end{align*}

    For (ii), we can check exactness on an affine cover, so we reduce to the case where \(X, Y\) are affine. So \(\mcF = \widetilde M, \mcG = \widetilde N, \mcK^\bullet = \widetilde{K^\bullet}, \mcL^\bullet = \widetilde{L^\bullet}\). By (i), we reduce to a statement about modules, showing that if \(M \to K^\bullet, N \to L^\bullet\) are resolutions, then
    \[M \otimes_k N \to K^\bullet \otimes_k L^\bullet\]
    is a resolution. That is,
    \[\HH^n(K^\bullet \otimes_k L^\bullet) = \begin{cases}
        M \otimes_k N & \text{if }n = 0 \\
        0 &\text{otherwise}
    \end{cases}\]

    Since 
    \[\HH^n(K^\bullet) = \begin{cases}
        M &\text{if }n = 0 \\
        0 &\text{otherwise}
    \end{cases}\]
    This follows from the na\"ive K\"unneth formula.
\end{proof}

\begin{proof}
    [Proof of \cref{thm:kunneth}] Take open affine covers \(\mcU, \mcV\) of \(X\) and \(Y\) respectively. So we have \v Cech resolutions,
    \[\mcF \to \check \mcC^\bullet(\mcU, \mcF) \qqtext{and}\mcG \to \check\mcC^\bullet(\mcV, \mcG)\]
    By the lemma, we get a resolution
    \[\mcF \boxtimes \mcG \to \mcK^\bullet\]
    where
    \[\mcK^\bullet = \check\mcC^\bullet(\mcU, \mcF) \boxtimes \check\mcC^\bullet(\mcV, \mcG)\]
    Now note
    \[\mcK^n = \bigoplus_{p + q = n}\left(\prod_{\# I = p + 1, \# J = q + 1}\mcK_{I, J}\right)\]
    where
    \[\mcK_{I, J} = (\iota_I \times \iota_J)_*(\mcF \boxtimes \mcG)\]
    where \(\iota_I : U_I \to X, \iota_J : V_J \to Y\) are the inclusion maps. This is acyclic, as for the usual \v Cech complex. Thus,
    \[\HH^*(X \times Y, \mcF \boxtimes \mcG) = \HH^*(\Gamma(X \times Y, \mcK^\bullet))\]
    Now
    \[\Gamma(X \times Y, \mcK_{I, J}) = \Gamma\left(U_I \times U_J, (\mcF \boxtimes \mcG)\vert_{U_I \times U_J}\right) = \mcF(U_I) \otimes \mcG(U_I)\]
    by the lemma. Thus,
    \[\Gamma(X \times Y, \mcK^\bullet) = \check \mcC(\mcU, \mcF) \otimes \check \mcC(\mcV, \mcG)\]
    So by na\"ive K\"unneth, the cohomology of this in degree \(n\) is
    \[\bigoplus_{p + q = n}\HH^p(X, \mcF) \otimes_k \HH^q(Y, \mcG)\] 
\end{proof}
