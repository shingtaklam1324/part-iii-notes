\section{Motivation}

Symplectic topology is the study of global phenomenon of \emph{symplectic manifolds}, which are a pair \((M, \omega)\), where \(M\) is a smooth manifold, and \(\omega\) is a non-degenerate closed \(2\)-form on \(M\). In particular, non-generacy implies the map
\begin{align*}
    \T M &\to \T^* M \\
    v &\mapsto \omega(v, \cdot)
\end{align*}
is an isomorphism.

\begin{example}
    \(\R^{2n}\) with coordinates \(x_1, y_1, \dots, x_n, y_n\) is a symplectic manifold, with
    \[\omega_{\text{std}} = \omega_0 = \sum \dd x_i \wedge \dd y_i\]
\end{example}

\begin{example}
    Let \(\Sigma\) be a surface of genus \(g\). Then any volume form makes \(\Sigma_g\) into a symplectic manifold.
\end{example}

Why study such manifolds? Some motivation from classical mechanics: Say we have a phase space \(X\) encoding position and momentum of some particles in a physical system. For example, we have a pendulum with angular coordinate \(\theta\), and angular momentum \(p = m\dot\theta\). The phase space is then \(S^1 \times \R\).

Given \(H : X \to \R\), encoding the total energy of a configuration, we want a vector field \(\mcX_H\) such that the trajectory \(x(t)\) satisfies
\[\dot x(t) = \mcX_H(x(t))\]
It's not enough to know that \(H\) is constant on trajectories, i.e. \(\dd H(\mcX_H) = 0\), since this is a co-dimension 1 condition. Recall if \(X\) has symplectic form \(\omega\), then we can take \(\mcX_H\) such that
\begin{equation}
    \label{eq:ham-vf}
    \omega(\mcX_H, \cdot) = \dd H
\end{equation}
Indeed, every phase space has such a symplectic form. Note that \(\omega\) is non-degenerate if and only if \cref{eq:ham-vf} has a solution for all \(H\), and \(\omega\) being closed is that \(\omega\) is preserved under the flow of \(\mcX_H\).

\begin{example}
    [harmonic oscillator] In this case, \(X = \R^2\), with coordinates \(p\) for momentum, \(q\) for position. The symplectic form is
    \[\dd p \wedge \dd q = r \dd r \wedge \dd\theta\]
    where \((r, \theta)\) is polar coordinates on \(X\).
    This has Hamiltonian
    \[H = \frac{1}{2}(p^2 + q^2) = \frac{1}{2}r^2\]
    Hence
    \[\dd H = r \dd r\]
    Thus, \(\mcX_H = \pdv{\theta}\).
\end{example}

\subsection{Mathematical perspective}

A question to keep in mind is: How does symplectic geometry compare to e.g. Riemannian geometry, complex geometry etc.

In this context, \(\dd\omega = 0\) is a form of ``flatness''. Suppose \((Y, g)\) is a Riemannian manifold, i.e. we have \(g \in \Sym^2\T^* Y\) non-degenerate. It is a fact that \((Y, g)\) is locally isometric to \(\R^n\) with the Euclidean metric if and only if the curvature \(F\) of \(g\) vanishes. That is, \(g\) is flat. 

On the other hand, suppose \((Z, J)\) is an almost complex manifold. That is, \(J \in \End(\T Z)\), with \(J^2 = - \id_{\T Z}\). One example would be \(\C^n\), with \(J(z) = iz\). One question is, when is \((Z, J)\) locally isomorphic to \(\C^n\)? That is, when is \((Z, J)\) a complex manifold. A difficult result in analysis, called the Newlander-Nirenberg theorem, shows that this occurs if and only if the Nijenhuis tensor,
\[\mcN_J(v, w) = [Jv, Jw] - J([v, Jw] + [Jv, w]) - [v, w]\]
vanishes

\begin{theorem}
    [Darboux] A manifold \((X, \omega)\) with non-degenerate \(2\)-form \(\omega\), is locally modeled on \((\R^{2n}, \omega_{std})\) if and only if \(\dd\omega = 0\).
\end{theorem}

Finally, symplectic topology is ubiquitous in research in geometry and topology, e.g. global topology, algebraic geometry and so on.

\section{(Symplectic) linear algebra}

Let \(V\) be a vector space, over a field \(\mathbb F\) of charactistic 0, with \(\dim(V) = n\). \(V^* = \Hom(V, \mathbb F)\) will denote the dual.

Define \(\mathbb F\)-algebras
\begin{align*}
    \T(V) &= \bigoplus_{i=0}^\infty V^{\otimes i} \\
    \Lambda^*(V) &= \frac{\T(V)}{\inner{v \otimes v}}
\end{align*}
If \(\{e_1, \dots, e_n\}\) is a basis for \(V\), then
\[\{e_{i_1} \wedge \cdots \wedge e_{i_k} \mid i_1 < \cdots < i_k\}\]
is a basis for \(\Lambda^kV\). Using this,
\[\dim(\Lambda^kV) = {n \choose k}\]

\begin{proposition}
    \(\Lambda^k(V^*)\) is isomorphic to the space of alternating multilinear maps
    \[V^{\otimes k} \to \bb F\]
\end{proposition}

\begin{proof}
    The map is given by
    \[e_{i_1}^\vee\wedge \cdots \wedge e_{i_k}^\vee \mapsto \sum_{\sigma \in S_k}\sign(\sigma)e_{i_{\sigma(1)}}^\vee\otimes \cdots \otimes e_{i_{\sigma(k)}}^\vee\]
    The rest is left as an exercise.
\end{proof}

In particular, \(\Lambda^n(V^*) = \Lambda^{\text{top}}(V^*)\) is (non-canonically) isomorphic to \(\Span\{\det\}\), or volume forms.

\begin{definition}
    A \emph{symplectic form} on \(V\) is \(\omega \in \Lambda^2(V^*)\), such that \(\omega : V \times V \to \bb F\) is a perfect pairing\footnote{That is, \(\omega(v, \cdot)\) induces an isomorphism \(V \cong V^*\).}.
\end{definition}

\begin{example}
    Let \(M^{4m+2}\) be an oriented manifold, and \(V = \HH^{2m+1}(M; \Q)\). The pairing
    \[\inner{\alpha, \beta} = \int_M\alpha\cup\beta\]
    is a symplectic form.
\end{example}

\begin{example}
    Let \(V = \R^{2n}\), with basis \(\{x_i, y_i\}\), with dual basis \(\{e_i, f_i\}\). We can define
    \[\omega = \sum_{i=1}^n e_i \wedge f_i\]
    More generally, if \((V, \omega_V), (W, \omega_W)\) are symplectic, then so is
    \[(V \oplus W, \omega_V \oplus \omega_W)\]
\end{example}

We can write
\[\omega(v, w) = v \vdot J_0 w\]
where
\[J_0e_j = f_j \qqtext{and} J_0f_j = -e_j\]
If we use complex coordinates \(z_j = x_j + iy_j\), then \(J_0\) is just multiplication bu \(i\).

Let \((V, \omega)\) be a symplectic vector space. Let \(W \sse V\) be a subspace. Define
\[W^\omega = \{v \in V \mid \omega(w, v) = 0 \text{ for all }w \in W\}\]

\begin{definition}
    \(W\) is
    \begin{enumerate}
        \item \emph{isotropic} if \(W \sse W^\omega\),
        \item \emph{coisotropic} if \(W^\omega \sse W\),
        \item \emph{symplectic} if \(W \cap W^\omega = 0\),
        \item \emph{Lagrangian} if \(W = W^\omega\). That is, it is isotropic and coisotropic.
    \end{enumerate}
\end{definition}

\begin{example}
    Take \(\R^{2n}\) with the standard symplectic form
    \[\omega = \sum_i \dd x_i \wedge \dd y_i\]
    Then \(\Span\{x_1, x_2\}\) is isotropic. In fact, \(\Span\{x_1, \dots, x_n\}\) is a Lagrangian subspace. On the other hand, \(\Span\{x_1, y_1\}\) is a symplectic subspace.
\end{example}

\begin{remark}
    For \emph{any} subspace \(W \sse V\),
    \[\dim(W) + \dim(W^\omega) = \dim(V)\]
    and we have that \((W^\omega)^\omega = W\).
\end{remark}

\begin{theorem}
    Given any symplectic vector space \((V, \omega)\) over \(\R\), there exists a linear isomorphism \(\Phi : V \to \R^{2n}\), such that \(\Phi^*\omega_0 = \omega\).
\end{theorem}

\begin{proof}
    We induct on \(\dim(V)\). Choose any \(v_1 \in V\) non-zero. By non-degeneracy, there exists \(w_1 \in V\) such that \(\omega(v_1, w_1) = 1\). Let \(V_1 = \Span\{v_1, w_1\}\). Define \(\Phi_1 : V_1 \to \R^2\), by \(\Phi_1(v_1) = x_1\) and \(\Phi_1(w_1) = y_1\). This satisfies that \(\Phi_1^*\omega_0 = \omega\vert_{V_1}\).

    Define \(V_2 = V_1^\omega\). Then \(V_1\) and \(V_2\) are symplectic, and \(\dim(V_2) = \dim(V) - 2\). By induction hypothesis, there exists \(\Phi_2 : V_2 \to \R^{2n-2}\), with \(\Phi_2^*\omega_0 = \omega\vert_{V_2}\). We can then define
    \[\Phi = \Phi_1 \oplus \Phi_2 : (V_1, \omega\vert_{V_1}) \oplus (V_2, \omega\vert_{V_2}) \to (\R^{2n-2}, \omega_0) \oplus (\R^2, \omega_0) = (\R^{2n}, \omega_0)\]
\end{proof}

\lec

In particular, symplectic vector spaces are always even dimensional.

\begin{corollary}
    \(\alpha \in \Lambda^2 V^*\) is symplectic if and only if \(\alpha \wedge \cdots \wedge \alpha \in \Lambda^{\text{top}} V^* = \R\) is non-zero.
\end{corollary}

\begin{proof}
    Note that
    \[\omega_{\text{std}}^n = x_1^\vee \wedge y_1^\vee \cdots \wedge x_n^\vee \wedge y_n^\vee\]
    is the usual volume form.\footnote{or maybe with a coefficient of \(n!\) in front of it...}
\end{proof}

Returning to linear algebra, we have
\[\Hom(V, V) \to \Hom(\Lambda^\text{top}V, \Lambda^\text{top}V) \cong \R\]
The composition is the \emph{determinant} \(\det : \Hom_*(V, V) \to \R\).

\subsection{Orientations}

Define
\[\ori_V = \frac{\{\text{ordered bases for }V\}}{\GL_+(V)} = \frac{\Fr(V)}{\GL_+(V)}\]
where we consider the \(\GL_+(V)\)-orbits, i.e. two frames are equivalent if they are related by a transformation with positive determinant.

In this case, \(\ori_V\) has two elements. Given any volume form \(\alpha\) on \(V\), there exists an induced orientation on \(V\), given by the sign of \(\alpha\) on a basis. In particular, any symplectic vector space has such a canonical orientation, induced by \(\omega^n\).

\subsection{Symplectomorphism}

\begin{definition}
    Define
    \[\Sp(2n) = \{\Phi \in \GL(\R^{2n}) \mid \Phi^*\omega_{\std} = \omega_{\std}\}\]
    if \(J_0\) is the matrix so that \(\omega(u, v) = u \vdot J_0 v\), then we have that
    \[\Sp(2n) = \{\Phi \in \GL(\R^{2n}) \mid \Phi^\T J_0\Phi = J_0\}\]
\end{definition}

\begin{example}
    For \(\R^2\), \(\omega\) is the standard volume form \(\dd x \wedge \dd y\). So preserving \(\omega\) is the same as preserving the volume form. Hence
    \[\Sp(2) = \SL(2, \R)\]
    In general, we have an embedding
    \[\Sp(2n) \sse \SL(2n, \R)\]
    since \(\omega^n\) is the standard volume form\footnote{maybe up to a factor of \(n!\)} on \(\R^{2n}\).
\end{example}

Note if \(\Phi\) commutes with \(J_0\), and \(\Phi\) preserves the inner product, then \(\Phi \in \Sp(2n)\). So
\[\GL(n, \C) \cap \mathrm O(2n) \sse \Sp(2n)\]
In fact, we have
\[\GL(n, \C) \cap \mathrm O(2n) = \GL(n, \C) \cap \Sp(2n) = \Sp(2n) \cap \mathrm O(2n) = \mathrm U(n)\]

\begin{proposition}
    The set \(S\) of symplectic forms on \(\R^{2n}\), as a subset of \(\Lambda^2(V^*)\) is \(\GL(2n, \R)/\Sp(2n)\), a homoegenous space.
\end{proposition}

\begin{proof}
    \(\GL(2n, \R)\) acts transitively on \(S\), with stabiliser \(\Sp(2n)\) for any point.
\end{proof}

Let \(\Lag(V)\) be the space of Lagrangian subspaces \(L\) of \(V\).

\begin{example}
    \(\Lag(\R^2)\) is just the one-dimensional subspaces of \(\R^2\), i.e. \(\R\P^1 = S^1\). More generally,
    \[\Lag(\R^{2n}) = \frac{\mathrm U(n)}{\mathrm O(n)}\]
\end{example}

\begin{example}
    Let \(V = C^\infty(S^1, \R)\), with
    \[\omega(f, g) = \int_{S^1}f\dd g\]
    Using integration by parts, this is alternating.
\end{example}

\section{Vector bundles}

If \(\pi : \mcE \to X\) is a vector bundle, we can define \(\Lambda^*\mcE \to X\), \(\Lambda^*(\mcE^*) \to X\), \(\ori_\mcE \to X\), and so on. We have a vector space \(\Gamma(\mcE)\) of global sections of \(\mcE\). In particular,
\[\Omega^k(X) = \Gamma(\Lambda^k(\T^* X))\]
is the space of \(k\)-forms.

\lec

\begin{definition}
    \(\mcE\) is \emph{orientable} if there exists a global section of \(\ori_\mcE\).
\end{definition}

\begin{example}
    [non-example] The M\"obius bundle over \(S^1\) is not orientable. More generally, for any vector bundle, \(\mcE \to S^1\), \(\mcE\) is trivial if and only if it is orientable.
\end{example}

Let \(M\) be a (connected smooth) manifold, and consider the tangent bundle \(\T M \to M\).

\begin{definition}
    \(M\) is \emph{orientable} if \(\T M\) is. If so, a choice of orientation for \(M\) is a choice of orientation for \(\T M\).
\end{definition}

Note that if \(M\) is orientable, then there exists two choices of orientation. If \(M\) represents one orientation, we will write \(\overline{M}\) for the other. Moreover, if \(M\) has a boundary, then \(\partial M\) has a canonical orientation, by saying \((e_1, \dots, e_{n-1})\) is positively oriented if \((\nu, e_1, \dots, e_{n-1})\) is positively oriented, where \(\nu\) is the outward pointing normal.

For compact \(M\), \(M\) is orientable if and only if \(\HH^n(M; \Z) \cong \Z\). A choice of orientation corresponds to a choice of generator in \(\{\pm 1\}\). Note that elements of \(\Diff(M)\) must either preserve or reverse orientation, which we can read off from \(\varphi_* : \HH^n(M; \Z) \to \HH^n(M; \Z)\).

\subsection{Cohomology and integration}

\begin{theorem}
    [de Rham] We have an isomorphism between de Rham cohomology and singular homology. Moreover, this is an isomorphism of rings, between the wedge product and the cup product.
\end{theorem}

Intuitively, the isomorphism is given by integrating a form over a chain.

\begin{theorem}
    [Stokes]
    Let \(M\) be a smooth \(n\)-manifold with boundary, and \(\alpha\) a compactly supported \((n-1)\)-form on \(M\). Then
    \[\int_M \dd\alpha = \int_{\partial M}\alpha\]
\end{theorem}

\lec

One corollary of Stokes is that we have a (perfect) pairing
\[\HH_k(M; \R) \otimes \HH^k(M; \R) \to \R\]
given by integration.

More generally, if \(N^k\) is an oriented submanifold of \(M\), \(\alpha \in \Omega^k(M)\) has \(\dd \alpha = 0\), then
\[\int_N \alpha = \inner{[N], \alpha}\]
where we take the pairing using real (co)homology of \(M\). The proof of this is beyond the scope of the course.

\begin{corollary}
    Let \((M^{2n}, \omega)\) be a closed symplectic manifold. Then \(\HH^{2k}(M; \R) \ne 0\) for all \(0 \le k \le n\).
\end{corollary}

\begin{proof}
    We know that \(\int_M\omega^n > 0\), since \(\omega^n\) is a volume form on \(M\). This shows that \([\omega^n] \ne 0\) in \(\HH^{2n}(M)\). Now noting that \([\omega]^n = [\omega^n]\) gives the result.
\end{proof}

For example, in \((\C\P^n, \omega_\text{FS})\), \(\omega = \PD[\text{hyperplane}]\). The class of \(\omega\) generates \(\HH^*(\C\P^n)\). Note on the other hand the result is false when \(M\) is open. For example, consider \(\R^{2n}\) with the usual symplectic form.

Suppose \(\varphi : M \to M\) is a diffeomorphism. Then \(\varphi^*\omega\) is another symplectic form. To see this,
\[\dd\varphi^*\omega = \varphi^*\dd\omega = 0\]
The fact that \(\varphi^*\omega\) is non-degenerate is clear, as \(\dd\varphi\) is an isomorphism on tangent spaces.

We'll say that \(\omega, \varphi^*\omega\) are \emph{diffeomorphic}. One question is: are all symplectic forms on \(M\) diffeomorphic? The answer is no for some \(M\), but we only know the result for very few \(M\).

\begin{definition}
    Define
    \[\Symp(M, \omega) = \{\varphi \in \Diff(M) \mid \varphi^*\omega = \omega\}\]
    This is the \emph{symplectomorphism group} of \((M, \omega)\).
\end{definition}

Clearly, we must have that \(\Symp(M, \omega) \sse \Diff_+(M, \omega)\), as symplectomorphisms preserve orientation.

\section{Vector fields and isotopies}

Let \(M^n\) be any manifold.

\begin{definition}
    An \emph{isotopy} of \(M\) is a smooth map \(\varphi : M \times \R \to M\), such that
    \begin{enumerate}
        \item for all \(t \in \R\), \(\varphi_t = \varphi(\cdot, t) : M \to M\) is a diffeomorphism,
        \item \(\varphi_0 = \id_M\).
    \end{enumerate}
\end{definition}

Equivalently, we can replace \(\R\) in the above with \((-\epsilon, \epsilon)\).

\begin{example}
    Define \(\varphi_t\) to be the rotation through angle \(t\) through a fixed axis on \(S^2\).
\end{example}

Any isotopy defines a time-dependent vector field \(X_t\), via
\[X_{t}(m) = \dv{s}\bigg\vert_{s = t}\varphi_s(m)\]
For compact \(M\), we have a correspondence
\[\{\text{time dependent vector fields } X_t\} \bij \{\text{isotopies }\varphi_t\}\]
For \(M\) non-compact, a flow might blow up in finite time. We are interested in how isotopies will act on tensors.

Let \(X \in V(M)\) be a vector field, with associated flow \(\varphi_t\) defined for all \(t \in \R\). Then for \(\alpha, \beta\) are covariant and contravariant tensors respectively. Define the \emph{Lie derivative}
\[\mcL_X\alpha = \dv{t}\bigg\vert_{t=0}(\varphi_{-t})_*\alpha\]
and
\[\mcL_X\beta = \dv{t}\bigg\vert_{t=0}(\varphi_t)^*\beta\]

We have the following properties:
\begin{proposition}
    \begin{enumerate}
        \item if \(Y\) is a vector field, then \(\mcL_XY = [X, Y]\),
        \item if \(\alpha\) is a \(k\)-form, then we have \emph{Cartan's (magic) formula}
        \[\mcL_X\alpha = \dd(\iota_X\alpha) + \iota_X(\dd\alpha)\]
        \item if \(f \in C^\infty(M)\), then \(\mcL_X f = X \vdot f = \dd f(X)\). This gives a map \(V(M) \to \Der_\R(\C^\infty(M))\), which is a homomorphism of Lie algebras.
        \item From Cartan, \(\mcL_X(\dd \alpha) = \dd\mcL_X\alpha\),
        \item \(\dd\alpha(X, Y) = X\alpha(y) - Y\alpha(X) - \alpha([X, Y])\) when \(\alpha\) is a \(1\)-form,
        \item if \(X_t\) is a time dependent vector field, with flow \(\varphi_t\), then
        \[\dv{t}\varphi^*_t\alpha = \varphi_t^*\left(\mcL_X\alpha\right)\]
    \end{enumerate}
\end{proposition}

\section{Lie derivatives continued}

Let \((M, \omega)\) be a symplectic form. When does an isotopy \(\varphi_t : M \to M\) preserve \(\omega\)? Let \(X_t\) be the associated time-dependent vector field, then \(\varphi_t\) preserves \(\omega\) if and only if \(\mcL_{X_t}\omega = 0\). In turn, by Cartan's formula, this is true if and only if \(\dd(\iota_{X_t}\omega) = 0\), i.e. \(\iota_{X_t}\omega\) is closed.

When if \(\iota_{X_t}\omega = \dd H_t\), for some \(H_t : M \to \R\)? We recover Hamiltonian dynamics. In this case, we call \(\varphi_t\) an \emph{Hamiltonian isotopy}.

Note that if \(M\) is compact, for any Hamiltonian function, we have an associated Hamiltonian isotopy associated to the vector field \(X_{H_t}\) given by
\[\iota_{X_{H_t}}\omega = \dd H_t\]

Note that if \(\HH^1(M; \R) = 0\), then all symplectic isotopy is a Hamiltonian isotopy, as every closed one-form is exact. In particular, we have a map given by the time \(1\) flow
\[C^\infty(M)\to \Ham(M) \sse \Symp_0(M)\]
Locally, the kernel of this map is the space of constant functions. Equivalently, if we quotient out the constant functions, then the map is locally injective.

\lec

\begin{theorem}
    [Moser] Let \((\omega_t)_{t \in [0, 1]}\) be a smooth family of symplectic forms on \(M\), \(M\) compact, satisfying \([\omega_t] = [\omega_0] \in \HH^2(M; \R)\) for all \(t\). Then there exists \(\psi \in \Diff(M)\) such that \(\varphi^*\omega_1 = \omega_0\).
\end{theorem}

Note that it is not true if \([\omega_t]\) is allowed to vary.

\begin{proof}
    [Proof (Moser's trick)] We seek an isotopy \(\varphi_t\) such that \(\varphi_t^*\omega_t = \omega_0\). Now since \([\omega_t]\) is constant,
    \[\left[\dv{\omega_t}{t}\right] = \dv{t}[\omega_t] = 0\]
    and so
    \[\dv{\omega_t}{t} = \dd\sigma_t\]
    for some \(\sigma_t \in \Omega^1(M)\). Now if \(\varphi_t\) is an isotopy, with associated vector field \(X_t\), then
    \begin{align*}
        \dv{t}(\varphi_t^*\omega_t) &= \varphi_t^*\left(\dv{\omega_t}{t} + \mcL_{X_t}\omega_t\right) \\
        &= \varphi_t^*\left(\dd\sigma_t + \dd \iota_{X_t}\omega_t\right)
    \end{align*}
    We would like this to be zero, since this would imply that \(\varphi_t^*\omega_t = \omega_0\). We can find \(X_t\) such that
    \[\sigma_t + \iota_{X_t}\omega_t = 0\]
    since \(\omega_t\) is non-degenerate. Since \(M\) is compact, letting \(\varphi_t\) be the flow of \(X_t\) gives the result.
\end{proof}

\begin{theorem}
    [Darboux's theorem] For any \(p \in (M, \omega)\), there exists a chart \(f : U \inj M\), sending \(0\) to \(p\), such that \(f^*\omega = \omega_{\text{std}}\vert_U\).
\end{theorem}

That is, there is no local symplectic geometry.

\begin{proof}
    Fix any chart \(h : U \inj M\), with \(h(0) = p\). Moreover, we can require that \(h^*\omega \in \Omega^2(U)\) is equal to \(\omega_{\text{std}}\) at \(p\), since this is just a linear algebra condition.

    Let \(U' \sse U\) be a neighbourhood of \(0\), such that \(\omega_t = \omega_{\mathrm{std}} + t(h^*\omega - \omega_{\mathrm{std}})\) is symplectic for \(t \in [0, 1]\). This exists since being non-degenerate is an open condition.

    By Moser's trick,
    \[\dv{\omega_t}{t} = h^*\omega - \omega_{\mathrm{std}} = \dd \sigma_t\]
    This exists since we can choose \(U'\) to be a disc, and so \(\HH^1(U') = 0\). Let \(X_t\) be such that
    \[\iota_{X_t}\omega_t = \dd \sigma_t\]
    Let \(\varphi_t\) be the flow of \(X_t\). In particular there exists \(U'' \sse U'\) open, such that for all \(t \in [0, 1]\),
    \[\varphi(U'') \sse U'\]
    In particular,
    \[\varphi_t^*\omega_t = \omega_{\text{std}}\]
    Now \(h \circ \varphi : U'' \to M\) satisfies the requirements.
\end{proof}

\section{Almost complex manifolds}

\begin{definition}
    [almost complex structure]
    Let \(X\) be a smooth manifold. Then \(J \in \End(\T X)\) is an \emph{almost complex structure} if \(J^2 = -\id\).
\end{definition}

\begin{example}
    When \(X = \C^n\), we have a canonical identification \(\T_zX \cong \C^n\). On this, \(J\) is multiplication by \(i\). We'll denote this by \(J_{\text{std}} \in \End(\T\C^n)\).
\end{example}

\begin{definition}
    [integrable] An almost complex structure \(J\) is \emph{integrable} if it is the pullback of \(J_{\text{std}}\) from an atlas of charts with holomorphic transition functions. That is, if \(X\) is a complex manifold, and \(J\) is multiplication by \(i\).
\end{definition}

\begin{definition}
    [compatible]
    Let \((M, \omega)\) be a symplectic manifold. We say that an almost complex structure \(J\) is \emph{compatible} with \(\omega\) if
    \begin{itemize}
        \item \(\omega(v, w) = \omega(Jv, Jw)\) for all \(v, w\),
        \item \(\omega(v, Jv) > 0\) for all \(v\) non-zero.
    \end{itemize}
    Equivalently, \(\omega(\cdot, J\cdot)\) is a Riemannian metric.
\end{definition}

Note that in this convention, we have
\[\omega_{\text{std}} = g(J\cdot, \cdot)\]
In this case, \((g, J, \omega)\) is a compatible triple.

\begin{proposition}
    Any symplectic manifold \((M, \omega)\) admits a compatible almost complex structure \(J\). Moreover, the set \(\mcJ(M, \omega)\) of all such \(J\) is contractible. So \(J\) is unique up to contractible choice.
\end{proposition}

\begin{proof}
    Pick any Riemannian metric \(g\) on \(M\). Then we have two isomorphisms
    \[\widetilde g, \widetilde \omega : \T M \to \T^* M\]
    Let
    \[A = \widetilde g^{-1}\widetilde \omega : \T M \to \T M\]
    If we have a compatible, triple, then \(A\) is an almost complex structure. Now
    \[\omega(u, v) = -\omega(v, u) = -g(Av, u) = -g(u, Av)\]
    and so we obtain that \(A^* = -A\). Here, \(^*\) denote the transpose. Hence \(AA^* = -A^2\). Now
    \[g(AA^*v, v) = g(A^*v, A^*v) > 0\]
    So \(AA^*\) is symmetric and positive definite. In particular, it is diagonalisable, with positive eigenvalues.

    Let \(J = \left(\sqrt{AA^*}\right)^{-1}A\). Then
    \[J^2 = -A^{-2}A^2 = -\id\]
    where we use the fact that everything commutes. Moreover,
    \[\omega(Ju, Jv) = g(AJu, Jv) = g(JAu, Jv) = g(Au, v) = \omega(u, v)\]
    and
    \[\omega(u, Ju) = g(-JAu, v) = g(AA^*u, u) = g(A^*u, A^*u) > 0\]
    So \(\mcJ(M, \omega)\) is non-empty. Choose \(J_0 \in \mcJ(M, \omega)\). Define
    \begin{align*}
        F : \mcJ(M, \omega) \times [0, 1] &\to \mcJ(M, \omega) \\
        F(J, t) &= J_t
    \end{align*}
    where \(J_t\) is the almost complex structure associated to the Riemannian metric
    \[g_t = tg_{J_0} + (1 - t)g_J\]
    Here, we are using the convexity of the space of Riemannian metrics. Then \(F\) defines a retraction of \(\mcJ(M, \omega)\) onto \(J_0\).
\end{proof}

\begin{definition}
    [Lagrangian submanifold]
    A submanifold \(L^n \sse (M^{2n}, \omega)\) is a \emph{Lagrangian submanifold} if \(\omega\vert_L = 0\).
\end{definition}

For example, \(\R^n \sse \C^n\), \(\T^n \sse \R^{2n}\), \(\R\P^n \sse \C\P^n\). If \(X\) is a projective variety defined over \(\R\), then \(X(\R) \sse X(\C)\) is Lagrangian.

\begin{example}
    If \(\phi : M \to M\) is a diffeomorphism, then it is a symplectomorphism if and only if the graph
    \[\Gamma_\phi \sse (M \times M, \omega \oplus -\omega)\]
    is Lagrangian.
\end{example}

\begin{theorem}
    [Weinstein neighbourhood]

    If \(L \sse (M^{2n}, \omega_M)\) is a compact Lagrangian, then there exists a neighbourhood \(U(L)\) of the zero section in \(\T^*L\), and a symplectic embedding \(U(L) \inj M\), sending the zero section to \(L\).
\end{theorem}

\lec

\begin{proof}
    Fix an almost complex structure \(J\) compatible with \(\omega_M\). This gives us an orthogonal decomposition
    \[\T M\vert_L = \T L \oplus J \cdot \T L\]
    This is orthogonal with respect to the metric \(g_J\). Let \(\Phi : \T^* M \to \T M\) be the lowering operator given by the metric. Now define
    \begin{align*}
        \varphi : U(L) &\to M \\
        \varphi(q, f) &\mapsto \exp_q(J \cdot \Phi(f))
    \end{align*}
    Here, \(\exp\) is the exponential map with respect to the metric \(g_J\). We can assume that \(\varphi\) is a diffeomorphism onto its image, by compactness of \(L\) and by shrinking \(U(L)\).

    Consider \(L \sse \T^*L\) embedded as the zero section. Note we have a canonical identification
    \[\T_{q, 0}(\T^ L) = \T_qL \oplus \T_q^* L\]
    With this,
    \[\DD \varphi(v, f) = v + J\cdot \Phi(f) \in \T L \oplus J \cdot \T L\]
    This is by the definition of the exponential map.

    We claim that \(\varphi^*\omega_M = \omega_L\) on \(L \sse \T^* L\). Indeed,
    \begin{align*}
        \varphi^*\omega_M((v, f), (v', f')) &= \omega_M((v + J\Phi(f), v' + J\Phi(f'))) \\
        &= \omega_M(v, J\Phi(f')) - \omega_M(v', J\Phi(f)) \\
        &= f'(v) - f(v') \\
        &= \dd\lambda_{\text{can}}((v, f), (v', f'))
    \end{align*}
    
    Now apply Moser's trick. We can write
    \[\varphi^*\omega_M - \omega_{\text{can}} = \dd\sigma\]
    for some \(\sigma \in \Omega^1(\T^* L)\), with \(\sigma\vert_L = 0\). The time-1 flow then gives the associated symplectic embedding. Here, we flow along the vector field \(X_t\) so that
    \[\iota_{X_t} \omega_{\text{can}} = \sigma\]
\end{proof}

\begin{remark}
    We've used that \(J : \T L \to \nu_{L/M}\) is an isomorphism. This tell us that (assuming \(L\) is oriented), the intersection number \([L]\cdot [L] = (-1)^{n+1}\chi(L)\).

    In this case, if \(\chi(L) \ne 0\), then \([L] \ne 0\).
\end{remark}

\subsection{First Chern class}

\begin{definition}
    A \emph{complex vector bundle} \(\mcE \to X\) is a real vector bundle, with am assocated endomorphism \(J \in \End(\mcE)\), with \(J^2 = -\id\).
\end{definition}

\begin{definition}
    A \emph{symplectic vector bundle} \(\mcE \to X\) is a vector bundle, with \(\omega \in \Gamma(\Lambda^2\mcE^*)\), such that \(\omega_x\) is a symplectic form on \(\mcE_x\).
\end{definition}

On each sympelctic vector bundle, we have a canonical choice of a complex structure \(J\), up to homotopy. Moreover, since we have a homotopy equivalence \(\Sp(2n) \simeq \mathrm{U}(n)\), classification of symplectic vector bundles and complex vector bundles are the same.

\begin{remark}
    Note that classification of complex vector bundles is \emph{not} the same as classification of holomorphic vector bundles.
\end{remark}

\begin{example}
    The tautological line bundle \(\mcL_{\mathrm{taut}} = \mcO(-1)\) over \(\C\P^n\) is a complex vector bundle.

    The \emph{canonical bundle} \(\mcO(1) = \mcL_{\mathrm{taut}}^*\) is also a complex vector bundle.
\end{example}

\begin{theorem}
    There exists a correspondence
    \[\{\text{complex line bundles on }X\} \bij \HH^2(X; \Z)\]
    by sending \(\mcL\) to \(c_1(\mcL)\).
\end{theorem}
